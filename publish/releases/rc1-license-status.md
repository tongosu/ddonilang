# RC1 라이선스·출처 확인 상태

저장소 최상위 [LICENSE](../../LICENSE)는 Apache-2.0 원문입니다. 여섯 Rust crate의 Cargo 메타데이터와 제삼자 의존성 고지를 공개 소스 대응 근거와 함께 대조합니다. 다른 저작물의 라이선스를 이 문서로 새로 배정하지 않습니다.

다섯 crate는 `Apache-2.0`, `lang`은 기존 `MIT OR Apache-2.0` 메타데이터를 유지합니다. 이 차이를 숨기거나 자동 재라이선스하지 않았습니다. RD-521의 경로별 적용·권리 확인 관문에서 적합 여부를 별도로 판단해야 합니다.

[제삼자 소프트웨어 고지](rc1/THIRD_PARTY_NOTICES.md)와 원문 사본은 원 출하 자료를 보존합니다. 이 목록은 보수적인 작업공간 의존성 목록이며 정확한 바이너리 연결 목록이나 법적 권리 확인 완료서가 아닙니다. JSON의 원 lock 해시는 역사 빌드 입력을 가리킵니다. 공개 workspace에 맞춘 lock과 같다고 표시하거나 원 값을 바꾸지 않습니다.

다음은 완료로 주장하지 않습니다.

- 독립검토 전의 RD-521 공개 권리 관문 통과.
- 개별 예제·자료·자산 전체의 권리 확인 또는 일괄 재라이선스.
- 원 출하물과 공개 소스 재빌드 결과의 바이트 동일성.
- 독립검토·사람의 사용 확인·P5/P6·정식 V1 완료.

필요한 라이선스 원문·NOTICE·경로별 적용·출처 결속이 미확인인 경우 공개를 진행하지 않습니다. 기존 문서의 판정과 알려진 제한을 임의로 바꾸지 않으며, 새 태그·공개 source 연결은 해당 변경분 검토 뒤에만 확정합니다.
