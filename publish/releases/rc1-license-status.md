# RC1 라이선스·출처 상태

저장소 최상위 LICENSE_SCOPE.md, NOTICE, LICENSES의 물리 본문과 CONTRIBUTING.md의 DCO 절차를 적용합니다. 프로젝트 소스의 기존 Apache-2.0 및 lang의 MIT OR Apache-2.0 권리를 보존하며 새 선언으로 덮어쓰지 않습니다.

공개 Cargo.lock과 고지 원 lock SHA는 동일합니다. Rust registry126개·고지126개 및 Node동봉8개 대조는 완료한 기존 근거를 재사용합니다. 그것이 교육자료·그림·fixture의 역사 원저작·권리를 증명하지는 않습니다.

LICENSE_PATH_INVENTORY.json은 파일별 경로·bytes·SHA와 적용 방향을, LICENSE_RIGHTS_PENDING.json은 원저작·출처·허용 조건이 아직 확인되지 않은 정확한 항목을 기록합니다. Git 작성자나 파일 위치만으로 이 미확인을 닫지 않습니다. 미확인 자료에는 CC BY-SA를 일괄 적용하지 않았습니다.

독립검토·배포 권리 확인·정확한 바이너리 dependency closure·바이트 재현성·P5/P6·Human은 별도입니다. 원문 고지와 실제 출처 자료를 보존하며 공개 admission 미완 상태에서는 push·태그·게시하지 않습니다.
