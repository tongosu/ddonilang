# RC1 직접 설치·사용 확인

이 안내는 시험 순서입니다. 아직 통과 기록이나 공개 배포 승인이 아닙니다. **독립검토와 또니의 봉인 승인 뒤 지정된 ZIP 하나로** 확인합니다. 개발자의 자동 검사와 또니의 직접 확인은 따로 기록합니다.

## 준비 — 설치 증거(P5)

1. 가능한 한 개발 도구·또니랑을 설치하지 않은 다른 Windows x64 PC를 사용합니다. 새 Windows 계정만 사용했다면 반드시 그렇게 적습니다. 새 계정은 개발 도구가 없는 깨끗한 PC와 같지 않습니다. PC 초기화나 기존 자료 삭제는 하지 않습니다.
2. 전달받은 최종 ZIP 이름·크기·SHA-256과 봉인 안내의 값을 비교합니다. 다르면 실행하지 않습니다. 시험 날짜, Windows 버전, 사용한 PC/새 계정 여부, 기존 Python·Rust·또니랑 설치 여부를 적습니다. 개인정보는 적지 않아도 됩니다.
3. ZIP 전체를 새 폴더에 풉니다. 실행 파일만 따로 꺼내지 않습니다. `START_SEAMGRIM.cmd`를 실행합니다. 별도 Python·Rust 설치 없이 작업대가 열려야 합니다. 자동으로 열리지 않으면 실행 창의 주소로 엽니다. 보안 경고·권한 상승·DLL 설치를 요구하면 우회하거나 설치하지 말고 화면을 남깁니다.
4. 인터넷을 끊고 시험할 수 있다면 연결 상태와 끊은 시점을 적고 시작·실행·저장·재열기를 확인합니다. 이 관찰만으로 엄격한 오프라인 재빌드/환경 격리 관문 전체를 통과했다고 쓰지는 않습니다.

## 직접 사용 — 또니 확인(P6)

아래 각 항목에 **통과 / 실패 / 해 보지 않음**을 적습니다. 실패한 작품이나 기존 정상 저장본은 지우지 않습니다. 저장·기록 마치기에는 시간이 걸릴 수 있으므로 완료 안내를 기다립니다.

1. **첫 계산:** 첫걸음 첫 계산을 실행하고 숫자를 바꿔 다시 실행합니다. 기대: 바뀐 결과가 나오고 원문을 계속 편집할 수 있습니다.
2. **여러 파일 작품:** `solutions/seamgrim_ui_mvp/samples/beta1_logical_counter/authored-project.json`을 가져옵니다. 입력 계약은 연결하지 않습니다. 파일을 오가며 편집하고 저장 → 실행 → 일시정지 → 저장합니다. 기대: 파일들이 남고 저장 완료가 표시됩니다.
3. **종료·이어 실행:** 브라우저와 실행 창을 모두 닫습니다. 다시 START → 같은 작품 다시 열기 → 한 마디 → 저장합니다. 기대: 저장한 상태에서 이어지고 처음부터 새로 시작한 결과로 바뀌지 않습니다. 재열기 전후 마디·값을 적습니다.
4. **테트리스:** 공식 모음에서 바로 열어 새 작업으로 저장하고 ▶ → 방향키 → 일시정지 → 한 마디 → 저장합니다. 기대: 판·블록 색·마디가 보이고 키 입력이 동작합니다. 잘림이나 가려짐도 확인합니다.
5. **기록:** 더 보기 → 입력 기록과 계약 → 기록 마치기·저장 → 고급 설정에서 재현 확인. 기대: 완료 기록과 원래 결과가 같다는 안내가 나오며 화면 마디가 갑자기 1로 돌아가지 않습니다. 창을 모두 닫고 다시 열어 재현 확인 → 저장한 시점에서 새 기록 → 한 마디를 진행합니다. 기대: 저장한 시점부터 이어지고 미완 기록을 완료라고 표시하지 않습니다. 원래 완료 기록은 보존합니다.
6. **탐구:** 이중 진자·LRL을 각각 열고 실행합니다. 으뜸·겹·곁·대상 선택 돋을 확인하고, 지원되는 초기조건을 바꿔 명시적으로 다시 실행합니다. 기대: 관찰할 수 있으며 이전 작품의 입력 칸이 남지 않습니다.
7. **틀린 원문:** 원문 사본을 남긴 뒤 일부러 문법을 틀리게 바꿔 실행합니다. 기대: 이유·위치가 나오며 마지막 정상 저장본은 유지됩니다. 원문을 되돌리고 저장본을 다시 엽니다.
8. **종료:** 작업대를 정상 종료한 뒤 다시 시작할 수 있는지 봅니다. 저장에 걸린 시간·불편한 조작·이상한 안내를 적습니다. 기존 자료나 폴더는 지우지 않습니다.

## 회신 양식

- ZIP 이름 / SHA-256 일치 여부:
- 시험 날짜 / Windows 버전 / 다른 PC 또는 새 계정:
- 기존 개발 도구·또니랑 설치 여부 / 인터넷 연결 상태:
- 준비 1~4 실제 결과:
- 사용 1~8 각각 통과·실패·미실행 / 기대와 다른 점 / 저장 소요 시간:
- 오류 문구·화면 사진(개인 경로·계정은 가려도 됨):

또니가 직접 확인한 범위만 Human 근거가 됩니다. 새 계정 시험·P6 확인을 P5 전체로 자동 확대하지 않습니다. `RC1_KNOWN_LIMITATIONS.md`를 함께 읽어 주세요. 강제 종료·정전·저장본 손상 시험은 이 일반 확인 순서에 포함하지 않습니다.
