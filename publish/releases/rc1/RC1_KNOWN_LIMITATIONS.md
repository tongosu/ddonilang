# RC1 후보 — 알려진 제한과 남은 관문

이 파일은 미완을 숨기지 않기 위한 목록입니다. 후보 ZIP은 봉인판·공개판·V1 완료판이 아닙니다. 독립검토 PASS, 또니 봉인 승인, 직접 설치·사용 확인은 서로 다릅니다.

| 항목 | 현재 경계 |
|---|---|
| 저장 속도 | 3초 목표 미달 표본이 있습니다. 저장·기록 마치기는 완료 안내를 기다려야 합니다. 단일 표본으로 목표 달성을 주장하지 않습니다. |
| Linux | 이 Windows ZIP은 Linux 제품이 아닙니다. 별도 개발 빌드의 계산·재생 근거가 있어도 보호 저장/전체 Linux 지원은 미완입니다. |
| 깨끗한 Windows 설치 | 개발 PC의 새 폴더 실행과 직접 CRT 의존 검사는 확인했지만 깨끗한 다른 PC 설치는 또니의 실행 근거를 기다립니다. 새 계정만으로 깨끗한 PC 전체 조건을 대신하지 않습니다. |
| P5 추가 관문 | 불일치 거부·격리 오프라인 재빌드·라이선스 최종 검토 등 미실행 항목을 보존합니다. 포함된 의존성 고지/검사만으로 전체 P5를 닫지 않습니다. |
| P6 | 또니가 직접 확인한 원문과 범위가 있어야 합니다. 개발자·다른 AI의 자동 스모크는 Human PASS가 아닙니다. |
| 결정 행렬 | 기존 이월 3칸은 NOT_RUN을 유지합니다. 기존 실패·보완 전 근거를 새 후보의 PASS로 덮지 않습니다. |
| 중단 복구 | 지원 증거가 있는 원래 완료 응답 조회와 명시 거부 경계를 구별합니다. 임의 과거 기록 복구·모든 Pending 수선·정전·전체 저장 접두어 관문을 보장하지 않습니다. |
| 원문 이관 | RD315 관찰 선언은 `내보임`입니다. 이관한 예제는 원문 해시가 바뀝니다. 옛 관찰 원문·옛 입력 기록을 몰래 수정하거나 새 원문과 같은 정체로 읽지 않습니다. |
| 추가 예제 회귀 | 이전 관측기의 모듈 문맥·조작 프로필 누락과 별도 실행 run_id 비교 실패는 보존됩니다. 실제 브라우저에서 새로 확인한 범위만 후속 보고서에 추가합니다. |
| 검사 전체 | 집중 검사·일부 회귀 통과를 전체 Rust 단일 실행 PASS로 바꾸지 않습니다. 과거 실패 기록은 보존합니다. |
| 확장 기능 | 세움보임 좌표 후속과 새 LSP 요청은 봉인 전 통합하지 않습니다. 기존 RC1 범위만 유지합니다. |

구체적인 실행 대상·SHA-256·검사 결과는 함께 전달한 후보 보고서와 독립검토 보고서를 기준으로 확인합니다. 문서가 있다는 사실은 해당 관문의 실행 증거가 아닙니다.
