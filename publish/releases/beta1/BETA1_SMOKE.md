# 베타1 직접 써 보기

이 ZIP은 동결 판단용 후보입니다. 아래에서 직접 확인한 항목만 통과로 적어 주세요.
자동 검사·개발자 검토는 이 체험을 대신하지 않습니다. 약 15~25분이면 됩니다.

1. **처음 열기.** ZIP을 새 폴더에 모두 풀고 `START_SEAMGRIM.cmd`를 실행합니다. 기대: 브라우저에서 작업대가 열립니다. Python을 설치하라는 말이 나오지 않습니다. 종료는 서버 창에서 Enter입니다.
2. **여러 파일 작품.** `samples/beta1_logical_counter/README.ko.md`의 작품을 가져와 보조 파일의 숫자를 고치고 원문을 저장합니다. 기대: 파일을 오가도 수정 내용이 남고 실행 결과에 반영됩니다. 예제 경로는 모두 `solutions/seamgrim_ui_mvp/` 아래입니다.
3. **종료하고 이어 하기.** 위 작품을 잠시 멈추고 실행 상태를 저장합니다. 브라우저와 서버를 닫았다가 같은 주소로 다시 열어 원문과 실행 상태를 다시 엽니다. 다음 한 마디를 진행합니다. 기대: 처음부터가 아니라 저장한 다음 마디로 이어집니다. 입력 계약을 묻는 경우 원래 계약을 직접 선택합니다.
4. **테트리스 저장.** 공식 모음의 테트리스를 열고 ▶를 눌러 방향키로 움직입니다. 잠시 멈추고 저장한 뒤 종료·재열기·이어 실행합니다. 기대: 판과 다음 진행이 유지됩니다. CLI로도 확인하려면 `samples/beta1_logical_tetris/README.ko.md`의 3마디 저장 + 4마디 이어 하기 순서를 따릅니다.
5. **이중 진자와 LRL.** 공식 모음에서 두 작품을 차례로 엽니다. 초기조건 끌기와 실행 중 조작을 안내대로 사용합니다. 기대: 조작 대상이 화면 근처에 있고 다른 작품으로 바꾸면 이전 입력이 남지 않습니다. 겹·곁을 닫거나 열어도 세계 계산은 달라지지 않습니다.
6. **정확한 분수.** 첫걸음 보충의 나눔수 예제를 열어 명시된 나눔수 문맥에서 `0.1+0.2`를 실행합니다. 기대: 정확한 `3/10`입니다. 일반 소수와 정확한 분수는 같은 종류로 취급하지 않습니다. 분수가 든 Tuple도 저장·재열기 뒤 같은 값을 유지합니다.
7. **대상과 원자.** 새 v25 원문에 아래를 붙여 실행합니다. 기대: `참`, `거짓`, `참`입니다. 임자만 새 대상을 만들고, 같은 대상을 가리키는 값은 같습니다. 폐기한 번호를 다음 대상에 재사용하지 않습니다. 원자는 별도 수동 등록 없이 쓸 수 있습니다. 폐기 문장을 두 번 쓰면 오류가 나야 합니다. 이 한 파일의 임시 정체를 저장 세계의 정체와 혼동하지 마세요.

   ```ddn
   병사:임자 := { 이름:글. }.
   표적 <- (이름="철수")인 병사. 첫 <- 표적 가리키기.
   (첫 == (표적 가리키기)) 보여주기.
   (대상=첫) 폐기하기.
   다음 <- (이름="영희")인 병사. (표적 == 다음) 보여주기.
   이름표 <- #철수. (이름표 == #철수) 보여주기.
   ```
8. **기록 재생.** 실시간 조작 뒤 ‘기록 중단·저장’을 누르면 미완 기록이 보존되고, 정상 재생은 거부되는 것이 현재 규칙입니다. 정상 V3는 입력 기록의 고급 설정에서 현재 원문·입력 계약과 맞는 미리 정한 입력 요청 JSON을 열어 만듭니다. 작품을 다시 열어 그 기록 파일을 재생하면 같은 결과가 나와야 합니다. 맞지 않는 기록은 이유를 표시하며 거부합니다. 옛 기록이나 미완 기록을 정상 기록으로 몰래 바꾸지 않습니다.
9. **오류와 복구.** 정상 예제의 이름 하나를 일부러 틀려 실행한 뒤 진단을 읽고 고칩니다. 기대: 위치와 이유가 나오며 기존 정상 저장본을 덮어 성공한 척하지 않습니다. 고치면 다시 실행됩니다. `<<-`는 베타2 예정이라는 명시 오류로 거부합니다.

각 번호에 통과 / 실패 / 해 보지 않음을 적고, 실패한 경우 작품·조작 순서·화면을 알려 주세요.
정전 복구와 모든 장애 상황의 복구 보장은 이번 스모크 범위가 아닙니다.
