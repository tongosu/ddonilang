# 또니랑 개발 스냅샷 — 2026-11-24

정식 V1이 아닌 개발 시험판(Pre-release)입니다. 기존 RC1과 과거 Release는 보존합니다.

## 내려받을 것

- 소스 ZIP: 공개 소스 사본입니다. 직접 빌드하려면 Rust/MSVC 등 안내된 개발 도구가 필요합니다.
- Windows x64 CLI ZIP: 포함한 ddonilang.exe와 예제 두 개를 실행하는 구성입니다. 실행에 Python이나 Rust를 설치할 필요는 없습니다. Windows용 명령줄 실행기이며 셈그림 전체 설치판이 아닙니다.
- 공개 SPEC ZIP: v0.9.1과 필요한 상속 문서를 원문 그대로 묶었습니다. 새 언어 판을 승격하지 않습니다.
- SHA256SUMS.txt: 각 첨부 파일의 SHA-256입니다.

## 포함한 개발 범위

한국어 호출·유한 호출 표면과 선택 진단 경로, 현행 언어·수치·증명·런타임과 작업대의 공개 가능한 소스를 갱신했습니다. 언어 판 V1~V9, 셈그림 응용, CLI·작업대·LSP 도구를 구분해 현황을 정리했습니다. 모든 언어 판과 모든 예제가 완성됐다는 뜻은 아닙니다.

컴파일의 원전은 W43의 고정 Native 소스이며, 공개 사본에서는 두 시험용 비공개 fixture 경계만 명시 입력으로 바꿨습니다. 실제 원본의 Native/WASM 혼합 출처와 이번 새 Windows Native 빌드를 구분합니다. 이 Release에 새 WASM이나 셈그림 통합 실행물은 넣지 않습니다.

## 확인 범위와 제한

공개 사본의 생산 cargo check, 변경 JavaScript 77파일 문법, 개인 경로·비밀/금지 자료 검사, 원격 기준 대비 patch/tree, 전체 소스 ZIP 복원을 확인했습니다. 이전 고정 제품의 한정 판정은 새 공개 실행물의 전체 판정이 아닙니다.

제외 fixture가 필요한 전체 cargo test, 모든 교재·저장/새 프로세스 복원, 전체 924항목·브라우저·Human·P5/P6·성능·정식 V1 완료는 주장하지 않습니다. 미완인 실행 갈래 host/Worker 후속·FFI 정식 ABI·내부 SSOT/우편함·작품 DB/인증 자료는 자동 포함하지 않았습니다.

코드는 기존 프로젝트/파일별 라이선스와 제삼자 고지를 유지합니다. 안내 문서는 CC BY 4.0입니다. 세부 빌드·검토·실행물 출처와 해시는 첨부 manifest 및 저장소의 publish/development를 참조해 주세요.

오류는 최소 원문·기대한 결과·실제 결과·사용한 Release 이름과 함께 https://github.com/tongosu/ddonilang/issues 에 남겨 주세요. 인증값과 개인 저장 자료는 올리지 마세요.
