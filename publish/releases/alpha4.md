# 또니랑 1.0.0-alpha.4

한국어로 쓰고 실행하며 바꿔 보는 개발 중 체험판입니다.

슬라이더와 끌기로 만지며 탐구하고, 조작 기록을 CLI와 셈그림에서 다시 실행할 수 있습니다.

Windows ZIP을 새 폴더에 풀고 START_SEAMGRIM.cmd를 실행하세요. Python 3.10 이상이 필요합니다. PowerShell에서는 ./START_SEAMGRIM.cmd를 사용합니다.

자동 실행 검증과 한정 독립검토 근거가 있습니다. 사용자 직접 스모크와 정식 출시 완료를 대신하지 않습니다.
입력 기록 이름·머리표·이전 형식과의 통합은 베타1 동결 전 검토 대상이며, 단계 철자는 잠정입니다.
