# 조건별 함수 — 현행 작성·검사·증거 계약

> CANDIDATE_R2 / NOT_CURRENT / DOCS_FIRST / INDEPENDENT_REVIEW_PENDING
> 규범 기준: 내부 v25.151.0 / RD001~709. 공개 CURRENT는 v0.8.1로 유지한다.
> 제품 지원·실행·독립 제품검토·공개 게시·Human은 이 문서 후보의 상태와 별개다.

## 작성과 첫 지원 범위

함수 머리의 구체 단항 입력과 결과씨, 귀속 조건별 몸통을 결속한다. 첫 실행/검사 목표는 무차원 정확 유리수·단일 입력·제한된 유한 구간 조건과 구체 단항 함수다. 집합 소속·다변수·양화 등 전체 표현 방향은 정확 문법/등록/자동 판정을 발급하지 않는다. 함수 머리만으로 runtime callable 등록이나 RD145 수학 참여가 완료되지 않는다.

정의역 D와 조각 C는 같은 typed 조건 체계를 쓴다. 유리수 산술항 사이 <, <=, >, >=, =:=, 같은 방향 연속 비교, 괄호·그리고·또는·아님(조건)을 결속한다. 아님이 항을 만들고 그리고가 또는보다 강하다. =:=는 수학 동등 관계이며 Boolean ==로 낮추지 않는다. 첫 범위의 혼합 비교 연쇄·효과식·대괄호 구간 표기를 임의 추가하지 않는다.

## 분할과 정의 가능성

- P2-A: 원 C가 D 밖 점을 포함하면 입력 오류다. D와 교집합해 자동 절단하지 않는다.
- P1-A: D 안에서 둘 이상 C가 참이면 값이 같아도 겹침 반례다. 행 순서·첫/마지막 선택으로 해소하지 않는다.
- 덮기: 선언 D 전체를 덮는다. 누락 점이 있으면 반례이며 D를 조각 합집합으로 줄이지 않는다.
- 값 정의 가능성: 각 활성 영역 D 그리고 C의 모든 점에서 값식 E가 정의되는지 별도 의무다. 분할 성공만으로 영분모·정의 미해소 등 값을 성공으로 만들지 않는다.

## 빈 함수와 작성 admission

명시 `정의역: 비어있음.`과 조각0개만 빈 함수 B로 별도 표시한다. 입력·결과씨는 빈 행에서도 명시한다. 일반 조건을 정확 해석해 공집합으로 알게 된 것은 같은 작성 의도가 아니다. 그 경우 명시 빈 정의역 요구의 입력 오류이고, 공허하게 참인 의무로 함수 검증·보임을 발급하지 않는다. 공집합 여부를 모르면 미확인/지원 밖/한도 사유를 남기고 성공을 보류한다. 명시 빈 정의역에 조각1개 이상, 빈 조각, 정의역 생략은 자동 보정하지 않는다.

## typed 공급과 제한 정의역 보존

공통 분석 owner가 선택 정의·필수 public pin·지역 binder·입력/결과씨·효과·source closure를 공급한다. 검사 대상마다 공통 입력 U 하나를 D·각 C·각 E에 연결한다. 원 binder와 U는 명시 대응하며 사용자 문자열이나 span을 정체로 발급하지 않는다. 직접 값식은 부모 정의/행에 귀속된 내부 단항 정의와 명시 수학 참여/정의 가능성 공급을 요구한다. 임의 일반 callable의 자동 참여가 아니다.

runtime 나눔수와 수학적 유리수 carrier의 대응·유한 실행 범위와 수학 전범위 정의 가능성은 구분한다. 제한 D를 함수값의 전달·적용에서 잃지 않는다. raw 함수 포인터나 같은 입출력씨만으로 제한을 지우지 않는다.

## 결과와 정확한 증거 소비

자료 구성·작성 admission·분할 검사·정의 가능성·명시 계산·세움/보임을 구분한다. 성립·반례·미확인과 입력/실행 오류, 빈 함수 표시를 서로 바꾸지 않는다. 계산은 입력∈D와 정확히 한 조각을 확인한 뒤 선택된 값식만 평가한다.

증거는 공통 입력·carrier·D·C·E·정의 closure·가정·검사 규약과 원 작성 admission에 결속한다. 다른 목표·binder·정의·가정·작성 분류의 증거를 바꿔 쓰지 않는다. 독립 checker가 정확 의무와 증거를 검사하고 정확한 세움의 보임으로 소비해야 한다. Bool/성공 플래그/hash만으로 증거를 발급하지 않는다.

## OPEN과 근거

실제 issuer/consumer·typed 연산/내부 정의 admission·제한 D carrier·checker profile·정확 identity/schema/wire·저장/제품은 OPEN이다. 제품 미구현이 위 승격 의미를 취소하지 않는다. 조건별 제품 착수·CLI/WASM/Chrome 지원을 이 문서로 발급하지 않는다.

근거: RD706 및 현행 LANG의 최종 승격 헤더·본문. 전체 표면 원문은 읽기전용 입력의 해당 파일에 보존돼 있고 새 번호·문법을 덧붙이지 않는다.
