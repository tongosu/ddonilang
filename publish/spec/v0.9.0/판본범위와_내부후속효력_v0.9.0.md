# v0.9.0 판본 범위와 내부 후속 효력

이 family는 공개 CURRENT가 지정한 뒤의 로컬 문서 현행판이다. 이 준비/전환으로 GitHub 게시·Release·제품 지원·Human을 승인하거나 수행하지 않는다.

## 규범 기준과 고정 원문

규범 본문은 내부 v25.151.0/RD001~709 기준의 검토·교정된 v0.9.0 R2.1이다. 예제14의 채비 원문 교정과 파생 결속은 문서 한정 독립 PASS/blocking0이며 예제 실행은 NOT_RUN이다. 예제14 검토와 제품·공개 사본 검토를 합치지 않는다. 고정 R2.1 입력과 R1/R2 실패판은 보존한다.

원문에 남은 CANDIDATE/NOT_CURRENT/당시 내부CURRENT·공개CURRENT는 그 입력의 기준 시점 기록이다. 이 판본의 효력과 현재 내부 상태는 이 문서와 새 manifest/seal이 설명한다. 원 후보의 과거 PUBLIC_POSTING_AUTHORIZED 문구가 이번 GitHub 게시 승인으로 이어지지 않는다.

## RD710 — 이름 가림 상태 보완

내부 v25.152에서 R1.1의 S1-A·조건부 교정 S2-A·RD173 기결정 제외 S3-A·명명 대조는 RD710으로 승격됐고 현재 v25.153에서도 유효하다. 따라서 아래 고정 `승인된후속안과_OPEN.md`의 이름 가림 “후속 후보/비현행”은 v25.151 당시 기록이며 현재 내부 상태가 아니다.

내부 현행은 지역 결속의 초기화 성공 뒤 lexical 가시성, 매개변수 본문 진입 가시성, 같은 root 동일 canonical 충돌, 검증된 이름/등록 소유 관계에서의 조건부 가림을 결속한다. X하→X하다·호출형 정확 관계/무인자 호출/선언 종류별 표면 제한의 별도 R2와 실제 producer/API/제품 범위는 이 승격으로 닫히지 않는다.

이 공개판의 규범 투영 범위를 RD710 전체로 소급 확장하거나 모든 예제가 해당 제품 경로에서 검증됐다고 주장하지 않는다. 내부와 공개 문서가 충돌할 때 내부 현행을 우선한다는 기존 권위 경계는 유지한다.

## RD711 — 첫 일차방정식 단계 계약

내부 v25.153은 첫 무차원 정확 Q 일차방정식의 정적 양변나누기/근거·계수·닫힌 비영 상수 동일 역수 유도, 모든 단계/첫실패·후속미검사·최종목표, 노트 전체원문/관찰·무효화·기존 저장새검사의 한정 계약을 추가했다. 이 단위는 v25.151 기준 고정 본문에 없으므로 이 공개판을 RD711 전체 투영·전체 V4 지원판이라고 부르지 않는다. 새 표면의 부재는 영구 금지라는 뜻도 아니다.

기존 proof/equality/checker 권위는 유지한다. 새 공리·변수계수/분모·범용 나눗셈·runtime Proof·새 wire나 무가정 정리·해 전체 분류는 이 범위 보완에 포함되지 않는다. 내부 문서 계약, 고정 제품의 별도 구현/검증, Human과 공개를 구분한다.

## 보존되는 상태

대체 근거의 PARTIAL·전체 폐기 UNKNOWN·전이 추론 금지, 승인된 비현행 후속안·다른 OPEN·제품 미지원/NOT_RUN·공식26/28/P5P6·기존 실패/제한/실제복구 이월을 보존한다. 본문 전체가 최신 내부 의미를 완전히 투영했다고 주장하지 않는다.

정체: private R2.1 ZIP SHA256 2e85a39b12d73bc6fe7f9856d64939f918bb038213a73ce2361b3f4b404c6cca, 원 공개 사본 ZIP SHA256 157eba34ef0a98a37268f5cd9b307c334eda65b60609456e630ffb6f63e83eda. source ID/고정 bytes/SHA는 SOURCE_AUTHORITY.md를 따른다. 내부 근거 원문·우편함·개인 로컬 경로를 여기에 동봉하지 않는다.
