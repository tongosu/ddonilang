# 공개 언어 SPEC v0.9.1

공개 CURRENT가 이 판본을 지정할 때 이 문서를 진입점으로 읽는다. 내부 v25.155.0의 RD-710~714 현행 부분을 공개할 규범 본문으로 정리했다. 이 판본에서 바뀌지 않은 규범은 고정된 공개 v0.9.0에서 계승한다. 그 판본의 판본 범위와 내부 판본 상태 설명은 당시 기록이다.

1. [이 판본의 RD-710~714 규범](SPEC_RD710_714_v0.9.1.md)
2. [작성 예와 거부 예](SPEC_EXAMPLES_v0.9.1.md)
3. [계승 본문 v0.9.0](../v0.9.0/SPEC_CURRENT_VIEW_v0.9.0.md)과 [계승 판본 봉인](../v0.9.0/SPEC_SEAL_v0.9.0.json)
4. [이 판본의 내용 목록](SPEC_CONTENT_SHA256_v0.9.1.json)과 [봉인](SPEC_SEAL_v0.9.1.json)

해당 주제의 설명이 충돌하면 아래 범위에서 이 판본이 우선한다.

| 조항 | v0.9.0 위의 변경 범위 |
|---|---|
| RD-710 | 지역 이름의 가시성, 소유가 검증된 가림, 같은 범위·같은 root의 충돌 명시 |
| RD-711 | 기존 정확 대수 보임의 정적 양변 나누기와 단계 검사 추가 |
| RD-712 | 등록 callable의 이름·종류별 호출·명시 무인자 계약 추가 |
| RD-713 | 지정된 직접 소유 호출의 결과 수용과 기존 미공개 경계 연결 추가 |
| RD-714 | 중괄호 줄기 입력이 없는 첫 한국어 규약에서 RD-326·408·712의 canonical 및 명시 full-form 제한만 부분 대체 |

기존 실패·미지원·UNKNOWN·개방된 기술 계약과 예제 검증 상태는 계승한다. 이 판본은 문서 규범을 제공한다. 제품 지원, 예제 신규 실행, Human 판정, 제품 배포는 이 판본의 판정 범위 밖이다.
