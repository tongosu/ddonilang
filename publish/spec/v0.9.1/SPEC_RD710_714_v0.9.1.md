# RD-710~714 공개 규범

이 문서는 기존 공개 규범에 추가되는 조항과 좁은 대체 범위를 정한다. 판본 효력과 읽는 순서는 [판본 명세](SPEC_MANIFEST_v0.9.1.md)를 따른다.

## RD-710 — 지역 이름과 가림

지역 이름은 자기 초기화가 성공한 뒤부터 선언 블록의 나머지와 중첩 범위에서 보인다. 선언 전과 자기 초기화 중에는 바깥 환경을 보고, 블록을 나가면 바깥 결속을 유지한다. 매개변수는 본문 진입부터 보인다. 초기화가 실패한 지역 이름을 부분 공개하거나 형제 블록으로 누출하지 않는다. 같은 lexical 범위에서 중복을 거부한다. 선언 머리, 기본값, 반복 및 특수 블록의 별도 범위는 기존 owner를 따른다. 함수 최외곽 본문의 지역 이름과 매개변수 사이에도 이 검사를 적용한다. 같은 root에서 값과 함수 정의의 canonical 이름이 같으면 선언 순서와 관계없이 거부한다. RD-173의 기존 충돌 규칙과 RD-592의 입증된 disjoint overload는 계속 적용한다.

안쪽 이름은 같은 철자의 바깥 이름을 가린다. 바깥 canonical과 그 등록 호출 꼴을 함께 가리는 관계는 실제로 검증된 이름 관계와 등록 소유에 한해 적용한다. 해소된 안쪽 값이 호출 불가능해도 바깥 정의나 alias로 돌아가지 않는다. 이름 관계가 공급되지 않은 경우에는 해당 관계를 UNKNOWN으로 남기며 그 가림 경계는 지원 밖이다. 철자 자르기, 유사도, 편집기의 표시 이름은 관계를 만들 수 없다.

## RD-711 — 정확한 등식의 양변 나누기

기존 정확 유리수 일차방정식 하나의 조건부 대수 보임에서 `양변나누기`를 정적 조작으로 쓸 수 있다. 허용되는 지역 단계나 이름 붙인 결과의 우변에서만 쓰고 `근거`와 `계수`를 각각 한 번 명시한다. 누락·중복·여분의 핀이나 조사형 대체는 거부한다. 근거는 같은 정의의 명시 가정 또는 같은 정의에서 이미 검사된 앞 단계 등식으로 해소돼야 한다. 계수는 허용된 닫힌 무차원 정확 유리수 식이며 0이 아니어야 한다. 변수의 존재와 0 분모는 약분이나 상쇄 전에 검사한다. 기존 정적 Q 항의 연산과 표현·예산 한도를 따른다. `t-t+1`과 `0*t+1`은 이 계수 자리를 충족하지 않는다.

검사기는 정확한 역수와 계수·역수의 곱이 1임을 확인하고, 근거 등식의 두 변에 같은 역수를 곱한 관계를 검사한다. 이어지는 `등식정리`는 별도 단계이며 양변을 각각 검사한다. 작성된 단계는 최종 목표에 쓰이지 않아도 검사 대상이다. 처음 실패한 단계와 원문 위치를 보존하고 뒤 단계는 미검사로 남긴다. 구문·해소 실패와 단계 거부를 구분하고 최종 목표를 따로 확인한다. 마지막 답의 대입이나 화면 관찰로 이 검사를 대신할 수 없다.

실제 가림이 있으면 정적 조작으로 되돌아가지 않는다. 일반 계산 문맥에서 이 철자를 전역 예약어로 삼지 않는다. 노트의 한 동작에 두 실제 원문 단계가 있으면 동일한 전체 원문에서 두 단계 모두 검사하고 표시한다. 관련 원문이나 의존을 편집하면 옛 검사의 표시를 무효화한다. 판본이 달라진 늦은 검사 응답도 적용하지 않는다. 재열기 직후 관찰 결과는 미생성이며 명시한 새 검사로 얻는다. 일반 계수 나눗셈·풀이 전체·무가정 정리·해 집합의 존재 또는 유일성 발급·새 공리·공개 증거 운반 형식은 이 조항의 범위 밖이다.

## RD-712 — canonical과 등록 호출 꼴

등록된 일반 한국어 호출에서 기본형 `…다`를 canonical로 삼으며, 정의 정본 이름과 실제 호출 꼴은 검증된 정의 소유 관계로 연결한다. 소유가 검증된 관계에서 `X`, canonical `X하다`, 등록된 `X하기`를 명시 역할로 구분한다. 내부 관계의 바탕 `X하`에서 새 호출 철자를 역으로 추출하지 않는다. 철자 정규화는 기존 NFC 계약을 따르고, 철자만 보고 소유를 추정하지 않는다.

실제 입력이 있는 셈씨는 등록된 짧은 꼴 또는 호출 꼴을 쓰고, 움직씨는 등록된 호출 꼴을 쓴다. 실제 입력이 없으면 기본값이 있어도 등록된 명시 호출 꼴을 쓴다. bare short form, 순수 바탕, 숨은 받는 이, 새 빈 괄호 규칙을 부여하지 않는다. 호출 꼴은 같은 정의·핀·결과씨·효과·실패·평가를 가리킨다. 특수 블록·이음씨·관계·연산자의 별도 표면은 각 계약을 따른다. 맨 canonical 이름의 함수값은 RD-085의 기대 함수씨와 범위를 따른다. invocation 안에서 결과자리는 canonical 하나다.

이 조항의 explicit full-form 공급과 `…다` canonical 제한은 아래 RD-714의 좁은 범위에서 대체된다. 나머지 기존 등록 계열과 다른 말씨의 등록 계약은 유지된다.

## RD-713 — 지정 호출의 결과 수용과 공개 경계

실행 구성 담당이 직접 소유한 특정 호출을 기존의 미공개 경계 및 그 실행·공개 owner에 실행 전에 결속할 수 있다. 이 한정 수용 조건은 해소된 호출의 바깥 typed `맺음`을 대상으로 한다. 호출·결과씨·권한·경계가 유일하게 결속되며 검사 시점이 성공 완료와 공개보다 앞서야 한다. 조건이 없는 일반 호출은 기존 계약을 따른다.

본문이 내부 결과 후보를 만든 뒤 경계 owner가 성공 완료와 공개 전에 이를 검사한다. 지정된 바깥 `안됨`은 해당 경계의 수용 거부이며, `잘됨(거짓)`이나 안에 실패값을 담은 `잘됨`은 이 조건의 거부가 아니다. 후자는 이 관문을 통과해도 기존 공개 검증을 거친다. 미시작·건너뜀·취소와 실제 hard failure는 각 기존 상태를 보존한다. 불완전하거나 검증할 수 없는 결과를 수용 성공으로 바꾸지 않는다.

거부되면 해당 경계의 새 admission을 중지하고 영향받는 시작된 하위를 기존 절차로 취소·합류한 뒤 그 경계의 미공개 patch와 outbox만 폐기한다. 해당 경계의 시작 전 세계를 보존한다. 성공 완료를 기다리는 후속 호출은 성공 완료가 승인되지 않으면 시작시키지 않는다. 선행 작업의 공개를 기다리는 관계에서는 이미 확정된 선행 상태를 보존한다. 상위 전파는 기존 구조적 관계를 따르고, 이미 공개된 세계나 무관한 경계에 소급 적용하지 않는다. 임의 하위 호출 검색, 일반 예외 처리, 사용자 callback에 의한 사후 판정, 새 작성 기호와 transport는 이 조항의 범위 밖이다. 실패의 원래 까닭과 경계의 수용 거부는 구분하며, 정확한 분류와 실행 영수증 연결은 열려 있다.

## RD-714 — 첫 한국어 이름·기/하기·조사 호출

중괄호 줄기 입력이 없는 첫 한국어 규약에서 canonical 이름 `C`를 선언 그대로 받는다. 품사를 판단하지 않는다. 바탕 집합은 `C`와, 이름이 `다`로 끝날 때 마지막 `다`를 한 번 뺀 이름으로 이룬다. 각 바탕에 `기`와 `하기`를 각각 붙인 완전한 유한 집합을 실제 정의 owner와 그 판본에 결속한다. `두배`는 `두배기·두배하기`, `나누다`는 `나누기·나누하기·나누다기·나누다하기`를 생성한다. 같은 정의에서 중복 유도된 철자는 한 번 등록하고 다른 정의는 같은 철자여도 소유를 병합하지 않는다.

실제 입력을 받는 셈씨의 canonical 직접 조사 호출과 생성 호출은 같은 정의·핀·결과씨·효과·실패에 결속한다. 무인자는 명시 기/하기 꼴을 사용한다. 순수 바탕은 자동 호출되지 않는다. 움직씨의 효과는 실제 선언 종류와 문맥을 따른다. 결과자리는 canonical 하나이며, 생성 꼴에 결과자리나 함수값의 alias를 부여하지 않는다. 맨 canonical 이름의 함수값은 RD-085의 기대 문맥을 따른다.

`두배`의 `의/을/를`은 같은 값핀, `나누다`의 `을/를`은 분자핀, `으로/로`는 분모핀에 대응한다. 라틴 이름·한글 이름·숫자·괄호 뒤의 조사는 공통 분석이 실제 선언·핀 후보를 보존해 유일하게 해소한다. 문자열 잘라내기, 등록 순서, 최장 일치, UI 추측으로 후보를 고르지 않는다. 가림·충돌·입증된 disjoint overload와 원문 순서 단일 평가를 유지한다. `d를 (e의 두배)로 나누기`의 순서는 `d`, 괄호 안 `e`와 안쪽 호출, 그 값의 분모 결속과 바깥 호출이다.

이 범위에서 RD-326·408·712의 `…다` 전용 canonical 및 explicit full-form 전용 공급을 부분 대체한다. RD-570의 유한·정확 등록과 자연어 비권위, 그 밖의 RD-712, 다른 말씨 등록, RD-709·713의 실행 경계는 유지된다. 기존 원문의 판본과 저장 정체를 자동 승격하거나 이름을 바꾸지 않는다. 서식 변경으로 생기는 원문 bytes·span 차이와 의미 보존을 구별한다.

중괄호 줄기 새 문법, 구판 full-form 이관, 시작 칸과 훅, 전체 어미와 제어 의미, 새 `~` 경계, 괄호 없는 중첩은 이 효력 밖이다. 이 문서는 실제 profile identity, 등록/API, 파서, 저장 형식을 발급하지 않는다.
