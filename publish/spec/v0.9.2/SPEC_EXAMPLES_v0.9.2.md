# RD715~719 작성 예와 거부 경계

아래는 규범의 역할을 설명하는 문맥 조각이다. 완성 실행 원문이나 실행 PASS로 표시하지 않는다. 이번 판의 신규 제품 실행은 NOT_RUN이다. 주변 모형·선언·프로필·owner·핀·판본은 실제 제품이 공급해야 하며 생략 부분을 UI나 테스트 변환으로 채우지 않는다.

## 명시 고정 RK4 방법의 서로 다른 두 층

```text
고정시간방법 <- (방식:#고정RK4, 간격:0.015625@s, 내줌간격:0.125@s).
```

기존 `풀기` 호출의 `푸는법=고정시간방법` 받는자리에 이 recipe를 결속한다. 계산격자 위의 끝과 정수배 관찰간격, 기존 모형·들임·내줌 소유와 실패 규칙을 함께 검사한다. 이 조각만으로 모형 실행이나 표본 공급을 주장하지 않는다. 정밀생략, 개별 RD607 RK4 callable, recipe 내부 방식은 같은 호출이 아니다.

## 닫힌 카드의 정상·반례가 공유하는 목표 머리

기존 정상/반례 원전에서 같은 목표 머리는 다음과 같다. 카드와 두 호출의 선언·판본은 각각의 전체 원전에서 해소한다.

```text
(면:카드~을) 두길이같다:(((면=면) 윗길가기) =:= ((면=면) 마지막에적용하기))보임:셈씨 := {
```

이 한 줄은 완성 원문이 아니다. 두 호출은 같은 `면`을 명시 핀으로 받고 각각 한 개의 카드→카드 정의에 유일하게 결속돼야 한다. 마지막 함수 본문이 다른 정상과 반례도 먼저 같은 목표 해소 관문을 통과해야 한다. 참거짓·제같음 검사·일반 셈씨 전개·검사된 반증 발급은 그 뒤 별도 계약이다. 이 머리의 수용에서 자동 보임을 만들지 않는다. 구판 원전의 full-form 등록을 RD719의 새 줄기로 재해석하지 않는다.

## 시작 참조와 훅

기존 모둠 시작 선택 자리에서 정의 canonical이 `인사`면 `정의=인사`, `나누다`면 `정의=나누다`로 그 정의를 참조한다. 이는 자리 문맥의 예이며 새 모둠 문법이나 무인자 실행을 제안하지 않는다. `인사하기`에서 어미를 잘라 정의를 추정하지 않는다.

선택 시작 본문과 단일 root에서 기존 시작·매마디 수명 및 원문순서를 적용한다. 훅 있는 시작을 일반 호출하거나 다른 일반 정의에 훅을 넣는 것은 거부한다. 훅 없는 일반 움직씨를 모두 금지하지 않는다. top-level 공존 Q4는 미지원이 아니라 **의미 OPEN**으로 유지하며 두 번째 진입을 발급하지 않는다.

## E={기}의 집합 설명 검산 — 제품 등록 아님

| C / S | 완전 생성 집합 G |
|---|---|
| 두배 / 없음 | 두배기, 두배하기 |
| 나누다 / 없음 | 나누기, 나누하기, 나누다기, 나누다하기 |
| 돕다 / {도우} | 돕기, 돕하기, 돕다기, 돕다하기, 도우기, 도우하기 |

품사나 자연스러움으로 꼴을 빼지 않는다. 같은 정의의 중복 유도만 집합 하나이며 다른 정의의 충돌은 유일해소·소유·scope·입증된 overload 검사에 맡긴다. 이 표는 문서 공식 검산이며 실제 profile/등록/파서 실행 검사가 아니다.

## 거부·열린 조건 구분

| 입력 상황 | 요구되는 처리 |
|---|---|
| 고정 RK4의 끝/관찰간격이 계산격자에 맞지 않음 | 거부. 보간·끝점 축소·fallback 금지 |
| 카드 양쪽 호출의 면/카드 선언/핀/의존판본이 다름 또는 복수 해소 | 원문 해소 거부. 목표 참거짓과 구별 |
| 시작 참조가 0개/복수이거나 기존 executable 조건 위반 | 실행 전 거부. suffix 추측·새 alias 금지 |
| 훅 있는 시작의 일반 호출·다른 일반 정의의 훅 | 거부. 일반 움직씨 전체 금지 아님 |
| 새 줄기 규약을 구판 full-form 저장 원문에 자동 적용 | 소급변환 금지. 실제 손실만 구체 이행 검토 |
| Q4·전체 어미/제어 의미·정확 profile/등록 미공급 | OPEN/공급 부족을 유지. 해 없음·보임 실패·지원 완료로 바꾸지 않음 |

위 표는 요구된 계약과 경계를 설명한다. 새 실행검사 여섯 건 PASS라는 뜻이 아니다. 기존 공개091의 거부 예·UNKNOWN을 지우지 않는다.
