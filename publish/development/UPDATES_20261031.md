# 개발·계약 진행과 공개 범위 · 2026-10-31

공개 언어 SPEC은 **v0.9.0**입니다. 내부 문서 현행은 **v25.154.0 / RD001~713**이며, 공개 SPEC의 규범 기준 v25.151.0 / RD001~709와 구분합니다. 내부의 후속 승격·방향 채택이 공개 규범이나 제품 지원으로 자동 반영되지는 않습니다.

## 이번에 기록한 결과

- 내부 v25.154.0은 일반 호출 표면과 직접 소유한 실패 처리의 승인된 한정 의미를 반영했습니다. 화살표 방향 보존, 일본어 단일 호출 집합, 실행파일 표시 기본값의 후속 방향은 별도 상태로 관리합니다.
- 보개 최소 표시 지정은 표의 `열들=`과 점·선 그래프의 `가로=`·`세로=`, 해당 인자의 직접 관측 참조를 채택했습니다. 설계 한정 검토와 실제 정의·핀 등록, 실행, 저장·재열기, renderer 지원은 서로 다른 관문입니다. 이번 문서 게시가 이 작성 표면의 제품 지원 완료를 뜻하지 않습니다.
- 결과표 정의와 시간·열들 핀의 물리 발급·고정 정책을 채택했습니다. 실제 발급 자료·소유 관계·정확 판본·검증과 제품 소비의 완료 여부는 별도로 확인합니다. 기존 무인자 표·시간·저장 동작을 보존합니다.
- 다국어는 기존 한 함수의 제한된 실행·재열기 연결과 일반 모듈용 등록 생산자 반환을 구분합니다. 일반 등록 자료가 존재한다는 사실만으로 전체 일본어 문법·라이브러리·저장 지원이 생기지 않습니다.
- 두 작품 비교는 작품이 명시한 시계를 사용하는 방향입니다. 정확 계수 규약과 실제 완료 frame·원문·의존의 결속이 필요하며, 같은 단계 번호나 화면의 숫자만으로 같은 시각을 판정하지 않습니다. 외부 AI 정책과 실제 호출 허가는 별도입니다.

## 소스·실행물·검토의 범위

이 공개 저장소의 **기존 개발 소스 스냅샷은 유지**합니다. 이번 변경은 공개 진행 문서와 파일 목록의 갱신이며, 새 내부 개발 코드를 검토 없이 공개하거나 RC1 실행물을 교체하지 않습니다. 최신 개발의 고정 소스와 내부 근거는 각각의 비공개 보관 범위에서 관리합니다.

기존 RC1 태그·다운로드·라이선스·권리 제외 목록을 유지합니다. V2 공개 미리보기, 전체 버전 완성, 다른 PC·실사용·학생/Human 확인, 물리 IME·저장 복구의 미완을 자동 완료로 바꾸지 않습니다. 새 태그·Release·바이너리를 게시하지 않았습니다. 문서 채택, 구현, 실제 환경별 실행, 독립검토, Human과 배포는 각각 확인해야 합니다.
