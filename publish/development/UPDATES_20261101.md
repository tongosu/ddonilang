# 2026-11-01 개발·문서 진행과 공개 범위

내부 언어 문서는 v25.155.0 / RD001~714다. 공개 SPEC CURRENT는 [v0.9.0](../spec/CURRENT.md)이며 규범 기반은 내부 v25.151.0 / RD001~709다. 이후 내부 문서의 모든 내용이 공개 SPEC 규범으로 자동 승격된 것은 아니다.

## 이번에 확인된 고정 결과

| 범위 | 고정 결과와 한계 |
|---|---|
| 첫 한국어 조사형 교재 | 명사형 이름과 기/하기 호출·괄호 중첩을 쓰는 첫 범위가 내부 RD714로 승인됐다. 고정된 비공개 결합본의 작성자 검사에서 세 단독 호출14와 중첩2, 직접 수정 뒤3을 확인했다. 실제 화면·동일 브라우저 보관 및 새 서버 프로세스 뒤 명시 실행을 확인한 범위이며 Native 내구 DB/세계 cold 저장과 독립 제품 PASS는 별도다. |
| 표시·관측 | 결과표와 XY의 물리 등록은 각각 정확 자료에 대한 독립 물리검토 PASS다. 실제 원문 해소·수량 타입·단위·공동 표본·화면·저장은 각 제품 근거와 구분한다. |
| 제한 다국어 소비 | 제한 한 함수의 소비·무효화·진단 보존과 고정 Native 저장/재열기 근거가 있다. 전체 일본어·일반 DDL·새 어휘·모든 저장 환경의 완료가 아니다. 논리군 물리등록·생산 프로필의 물리검토도 실제 Bool 증거나 공개 실행 지원과 별개다. |
| 수학·학습 표시 | 전체 작품 관측, 표시/패키징, 저장 사전검사 교정은 각 고정 대상에 한정한 검토 근거다. 문제 입력 선정·조건부 단계 검사·무가정 증거·계산·학생 확인을 서로 대체하지 않는다. |

## 공개 소스·제품과의 경계

이번 GitHub 변경은 공개 가능한 진행 문서다. 기존에 공개된 코드·라이선스·RC1 태그·Release는 유지한다. 최신 비공개 작성자 고정 소스는 별도 공개 사본 적합성·제품 검토와 출처/라이선스 경계가 결속되기 전 공개 코드에 자동 이식하지 않는다. 새 바이너리·V1 정식 배포·Human 승인이 아니다.

공식 완료26/28과 잔여 P5/P6, 기존 실패·제한·미지원·NOT_RUN 및 실제 복구 이월을 보존한다. 키/인증 자료·개인 DB·내부 우편함·작업 로그·로컬 경로는 공개하지 않는다. AI를 활용한 개발 사실은 기여자 identity나 독립 판정과 구분한다.

고정 결과가 다음 통합본에 포함되는 범위와 실제 실행물 계보는 해당 새 대상에서 검증한다. 작성자 검사를 독립 PASS로, 로컬 파일 보관을 모든 환경의 내구 저장으로, 한 언어·환경의 성공을 전체 지원으로 확대하지 않는다.
