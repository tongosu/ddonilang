# 개발 진행과 공개 소스 범위 — 2026-10-29

현재 GitHub 공개 소스 스냅샷과 RC1 다운로드는 이후 개발된 모든 기능을 담은 최신 설치판이라는 뜻이 아닙니다. 새 바이너리·태그·Release를 이번 문서로 추가하지 않습니다.

## 실제 완료 범위

- V3 수학 탐구노트, V4 정확 유리수 풀이 단계, V5 배달 로봇: 각각 승인된 첫 사용자 흐름의 고정·한정 독립검토 완료. 전체 판이나 사용자 확인 완료가 아닙니다.
- V6: 고정 제안의 공통 검사·선택 적용·원문 복원·명시 저장/실행 첫 흐름 한정 PASS. 실제 외부 AI 연결은 포함하지 않습니다.
- V7: 검증된 의존 자료를 실제 DDN으로 소비하는 도구와 결합 변경분 한정 PASS. Native·WASM의 빌드 출처는 별도로 결속합니다.
- V8: 지정 closed helper의 독립 공급·소비 한정 판정이며 범용 패키지 생태계·공개 공급 신뢰 정책 완료가 아닙니다.
- V9: 지정 대표 자료의 읽기·검증·명시 새 실행과 원본 보존 첫 범위는 AI 독립검토까지 마감했습니다. 모든 옛판 호환·자동 이관·세계 이어 실행·Human 완료는 아닙니다. 이전 실패 기록은 보존합니다.
- 운동·물탱크 첫 모듬: 정확 계산·분 단위·속도/유입량0의 해 분류와 소비 연결에 대한 고정 비공개 모듬 한정 PASS입니다. 독립 새 원문 정상7/거부3과 작성자 저장/cold 재사용을 구분합니다. 이 소식은 현재 공개 실행물이나 공개 코드 전체가 그 최신 고정 제품과 같다는 주장이 아닙니다.

## 언어 문서

[공개 SPEC CURRENT](../spec/CURRENT.md)는 v0.9.0입니다. 규범 기준은 내부 v25.151.0/RD001~709이며 내부 현행 v25.153.0/RD001~711 전체의 투영판은 아닙니다.

v25.154.0의 일반 호출·명명 및 지정 호출 실패경계 후보는 전체 가족 문서조립 한정 PASS를 받았지만, Owner의 CURRENT 최종 승격 승인 전입니다. 현행153과 후보154를 구분합니다. C2·전체 receiver·기계 정규형·일본어/EXE·일반 RHS 복구와 기술 OPEN은 별도입니다.
