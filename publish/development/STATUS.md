## 최신 검수 기준과 공개 코드의 차이

후속 누적 검수본의 소스 기준은 `868ddd0d612696b67dd588a7af495723341b62ce`입니다. 일부 WASM은 별도 고정 소스 `54f8ca1f4bd3ff05938a5d3d129219749d84b123`에서 재사용했습니다. 두 실행물을 같은 새 소스로 빌드했다고 표시하지 않습니다.

해당 검수본의 숫자 변환 원문29·진단 앞원문·오류 선택·편집 후 폐기와 명시 실행·포장 변경은 독립검토에서 필수 교정 없이 통과했습니다. 전체 924항목, 전체 저장/새 프로세스 복원, 사람 검수 또는 출시의 일괄 통과를 의미하지 않습니다. 원문29는 사례 식별자이며 검사29개를 뜻하지 않습니다.

이 전체 소스 후보는 해당 고정본에서 여섯 runtime crate의 공개 대상과 동봉 UI 코드를 추출한 별도 공개 사본입니다. 기존 공개 자산·고지와 제외 경계를 보존하며, 미완인 보개 실행 갈래 후속은 포함하지 않습니다. 오프라인 생산 빌드 검사만 새로 수행했으며 공개 사본의 독립검토·전체 회귀·WASM 재빌드·실제 화면 실행은 아직 확인하지 않았습니다.
