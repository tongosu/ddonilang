# 또니랑

초등학교 졸업 전에 **기억으로 남는 작품을 하나 만들고 싶어서**, 1년 동안 준비하며 시작한 프로젝트입니다.

파이썬을 배우면서 할 수 있는 것은 많았지만, 처음에는 영어와 문법이 어렵게 느껴졌습니다. 스크래치는 쉽고 재미있었지만, 프로그램이 커지면 복잡해졌습니다. 그래서 **한국어로 읽히는 언어로 게임도 만들고 공부도 해 보면 어떨까** 하는 생각을 했습니다. AI와 함께 만들고 고쳐 가는 또니랑은 그렇게 시작했습니다.

또니랑으로 작은 계산을 해 보고, 이름을 붙이고, 조건과 반복을 써서 조금씩 프로그램을 만들어 봅니다. 누나와 함께 만들고 있는 셈그림에서는 코드를 고치고 결과를 바로 살펴볼 수 있습니다. 게임뿐 아니라 수학·물리·경제도 직접 바꿔 보고 배우는 도구로 만들고 싶습니다.

```ddn
3 + 4 보여주기.
```

계산에 이름을 붙이면 이렇게 부를 수도 있습니다.

```ddn
(값:수~의) 두배:수:셈씨 := {
    두배 <- 값 * 2.
}.
7의 두배 보여주기.
```

`7의 두배`처럼 읽히는 호출이 또니랑의 특징입니다. 아직은 만드는 중이라 어색한 곳도 있고, 고쳐야 할 곳도 있습니다.

## 한국어로 생각하고 설명하기

명령어만 한국어로 바꾸려는 것은 아닙니다. 값의 역할을 조사로 읽고, 계산하는 셈씨와 일을 수행하는 움직씨를 나누며, 자기 작품을 자기 말로 설명하는 언어를 만들고 싶습니다. 한국어처럼 보여도 컴퓨터가 상식으로 뜻을 추측하지는 않습니다. 이름과 씨, 받는자리와 호출이 분명하게 맞아야 합니다.

## 게임을 만들다가 공부도 한다면

공을 던지는 규칙은 포물선 운동 실험이 되고, 상점 가격을 바꾸는 규칙은 계산과 경제를 배우는 출발점이 될 수 있습니다. 그림을 보기만 하는 대신 숫자와 규칙을 바꾸고 왜 달라졌는지 원문을 따라가 봅니다. 셈그림도 같은 운동을 여러 관점에서 나란히 보고, 벡터와 측정값을 얹고, 상황을 비교하는 작업대로 키우고 싶습니다.

## 결과를 다시 확인하기

같은 원문과 같은 입력·실행 조건으로 결과를 다시 확인하는 방향으로 설계하고 있습니다. 화면 속도 때문에 계산이 달라지거나, 자료를 못 읽었는데 그럴듯한 기본값으로 넘어가는 일은 피하려 합니다. AI는 코드와 해설을 만드는 데 도움을 주지만, 맞는지는 실제 실행과 검사를 통해 확인합니다. 앞으로는 사람이 정한 규칙 안에서 AI가 실험하고 배우는 데에도 쓰고 싶습니다.

## 여섯 요소로 보는 큰 그림

**샘**은 입력, **누리**는 세계 상태, **이야기**는 규칙과 진행, **보개**는 보는 방법, **거울**은 기록과 다시 확인하기, **슬기**는 AI 협업층입니다. 지금 여섯 앱을 모두 제공한다는 뜻이 아니라, 서로 다른 책임을 섞지 않고 연결하려는 구상입니다. 작은 한국어 프로그램에서 게임과 수학·물리·경제 실험으로 이어 가고 싶습니다.

## 처음 배우는 사람을 위해

알파1에는 **첫걸음 10차시**를 준비했습니다. 계산과 이름에서 시작해 셈씨·움직씨, 조건·반복, 오류 읽기를 배웁니다. 원문을 읽고 결과를 예상한 다음 실행해 보고, 숫자나 규칙을 바꾸는 방식입니다.

학생용 PDF와 교사용 안내도 함께 준비했습니다. 배포 파일은 [Releases](https://github.com/tongosu/ddonilang/releases)에 올립니다. 현재 알파1 릴리스는 공개 전 확인을 위해 초안으로 두고 있습니다.

더 넓은 모습은 [전체 언어 길잡이](publish/guide/또니랑_전체언어_길잡이.md)에서 읽을 수 있습니다. 이 책은 목표로 하는 언어의 지도이며, 지금 실행하는 실습은 첫걸음 코스를 따릅니다.

## 이 저장소에서 해 볼 수 있는 것

언어와 실행 도구의 소스가 있습니다. Rust가 설치되어 있다면 다음 명령으로 확인할 수 있습니다.

```sh
cargo check --locked
```

현재 이 저장소의 소스와 준비 중인 알파1 실행파일은 서로 다른 시점의 버전입니다. 알파1 소스도 정리해서 반영할 예정입니다. 전체 문법의 설명은 [언어 스펙](publish/spec/CURRENT.md)에서 볼 수 있지만, 아직 모든 기능이 구현된 것은 아닙니다.
