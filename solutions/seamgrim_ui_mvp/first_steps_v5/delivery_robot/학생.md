# 로봇은 몇 번 움직이면 도착할까?

목적지는8칸 앞에 있습니다. 로봇이 한 마디에1/2칸씩 간다면 몇 번 움직여야 할까요? 이번 작품에서는16번입니다. 속도를1칸으로 바꾸면8번입니다. 칸/마디는 이 작품이 정한 논리적 척도이며 실제 초당 속도나 물리 단위가 아닙니다.

## 작품 열기

진행자가 준비한 R012 작업대를 START_SEAMGRIM.cmd로 시작합니다. ‘작품 자료 가져오기(⇧ 가져오기)’에서 V5 R2 묶음의 `배달로봇_등록작품.json`을 엽니다. 이 묶음은 작품과 실행 근거이며 실행파일 설치본이 아닙니다.

main.ddn에서 아래 한 줄을 찾습니다. 기본값1/16의 전체 도착은 이번 확인 범위가 아니므로, 먼저 확인된1/2로 바꿉니다.

```ddn
    속도:수 := 1 / 2.
```

상단 ‘저장’을 누르고 Native 원문 저장 완료를 확인한 뒤 ▶로 직접 실행합니다. 길·목적지·몸체·두 바퀴·안내 글이 보이고 로봇이 이동합니다.1/2일 때 목적지8칸에16번의 이동으로 도착합니다. 원문의 도착 값은 참이 됩니다. 도착한 뒤 ■로 중지합니다.

## 속도 하나 바꾸기

속도 줄만 다음처럼 바꿉니다.

```ddn
    속도:수 := 1.
```

원문 저장 완료를 확인하고 ▶로 새로 실행합니다. 이번에는8번의 이동으로8칸에 도착합니다. 같은 목적지인데 이동 횟수가 줄어든 이유를 설명해 보세요. 두 실험에서 바꾼 것은 속도 하나입니다.

작품은 매마디 이동칸과 지난마디를 갱신하다 목적지에 도달하면 위치를8로 맞추고 더 이동하지 않습니다. 화면 위의 마디 번호와 이 작품이 센 이동 횟수는 같은 숫자라고 단정하지 마세요. 도착 확인은 작품의 위치8·도착 참·기록한 이동 횟수를 함께 읽습니다.

## 원문을 보관하고 다시 열기

속도1인 원문의 Native 저장 완료를 확인한 뒤 브라우저와 Native를 정상 종료합니다. 같은 저장 위치·같은 브라우저 프로필로 다시 시작합니다. ‘내 작업’에서 저장한 작품을 엽니다. 현재 고정본의 기존 안내에서는 ‘명시 작품’으로 표시됩니다.

원문과 등록된 보개는 돌아오지만 자동으로 실행하지 않습니다. ▶를 눌러 새로 시작합니다. 이전에 도착했던 세계의8칸부터 이어가는 것이 아닙니다. 속도1의 원문을 새로 실행해 다시8칸에 도착하는지 봅니다.

Native 저장 자료가 ZIP이나 USB에 자동으로 담기는 것은 아닙니다. 다른 컴퓨터에서 여는 작업과 세계 이어 실행은 이번 수업의 확인 범위가 아닙니다.

## 무엇을 배웠을까?

- `속도:수 := ...`에서 수와 이름 있는 정의를 읽습니다.
- 움직씨 안의 시작·매마디·조건을 따라 이동칸과 도착 상태가 언제 바뀌는지 읽습니다.
- 길·원·다각형을 그리는 셈씨와, 그것을 실행 상태에 연결하는 보개짜임을 구별합니다.
- 값을 바꾸기 전에 예상하고, 실제 위치·도착·이동 횟수로 예상과 비교합니다.

이 로봇은 장애물과 충돌을 피하는 자율주행 로봇이 아닙니다.0·음수 속도나 키보드 조종은 이번에 확인하지 않았습니다.
