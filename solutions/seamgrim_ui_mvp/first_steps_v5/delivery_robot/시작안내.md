# V5 로봇 공개 소스 예제 안내

이 폴더는 새 실행 ZIP이나 설치판이 아닌 원문·교재 소스입니다. 학생.md와 교사용.md는 기존 고정 실험의 학습 참고이며 현재 공개 빌드의 검증 상태를 대신하지 않습니다.

원문은 ../../samples/v5_delivery_robot/root.ddn 및 main.ddn입니다. 같은 폴더의 authored-project.json은 기존 공통 API가 만든 원문 등록 자료이며 저장 권한·Proof가 아닙니다. 원문과 등록 JSON을 임의로 고쳐 해시를 맞추지 마세요.

개발자는 저장소의 publish/development/BUILD_SOURCE.md를 따라 Native CLI를 빌드하고, 저장소 최상위에서 다음 입력을 직접 실행해 확인할 수 있습니다.

```text
target/debug/ddonilang.exe 작품자료 실행 solutions/seamgrim_ui_mvp/samples/v5_delivery_robot/authored-project.json --마디수 128
```

기본1/16의 기대값은128마디에위치8·도착참입니다. 원 고정내부제품에서확인된값이며 새로운개발자빌드의PASS를자동승계하지않습니다. 1/2는16마디,1은8마디와비교합니다. 0/음수·장애물·충돌·세계이어실행·Human은이예제의완료범위가아닙니다.

현재 공개 RC1 다운로드는 이 후속 V5 실행물이라고 표시하지 않습니다. 웹작업대/WASM/저장 실습은 같은 소스의실행물·생성자산을갖춘후별도로확인하세요. Native저장은USB에자동이전되지않습니다.
