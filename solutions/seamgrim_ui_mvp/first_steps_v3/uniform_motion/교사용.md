# 등속운동: 같은 시각과 같은 목표 비교

## 목표와 선수 학습

학생은 위치와 이동 거리를 구별하고, 일정한 속도를 ‘같은 시간 동안 같은 위치 변화’로 설명한다. 표·그래프·위치를 대조하고 목표 도달 시간을 원식에 대입해 검산한다. 필요한 선수 지식은 분수의 곱셈, 시간·길이 단위와 좌표 읽기다. 전체 또니랑 문법을 먼저 이수할 필요는 없다.

## 공식 원문 두 개

기본 작품은 root.ddn/main.ddn, 수정 대조 원문은 속도2/main.ddn이다. 두 main의 비어 있지 않은 행은 속력의3/2→2 정의만 다르다. 학생은 기본 작품에서 그 한 줄만 직접 편집한다. 완성 원문은 대조용이며 자동 교체 도구로 편집 체험을 대신하지 않는다.

`탐구계수`와 `탐구시각`은 이 수업이 정의한 값 이름이다. `나눔수` 계수와 실제 길이·시간·속도 단위 기준을 공통 수학 생산자가 함께 검사한다. JS가 숫자를 읽어 단위를 추정하거나 모형을 다시 계산하지 않는다. 원문 예제는 R009 고정 Git 원문을 그대로 재사용하며 새 문법을 만들지 않는다.

## 예상값과 질문

| 입력 | 위치:0/2/4초 | 목표7m 도달 | 검산 |
|---|---|---|---|
| 처음1m, 속도3/2m/s | 1/4/7m | 4s | 1+(3/2)×4=7m |
| 처음1m, 속도2m/s | 1/5/9m | 3s | 1+2×3=7m |

표에서 각 시각의 위치를 읽은 뒤 그래프와 위치 그림에서 같은 값을 찾게 한다. 두 선을 서로 다른 맞춤 축으로 비교하지 않는다.0초 위치가 같고 이후 차이가 커지는 이유,2초 동안의 이동 거리가3m와4m인 이유를 학생이 설명하게 한다. 화면용 좌표·반올림·epsilon을 정확 비교의 근거로 쓰지 않는다.

## 저장·재열기 지도

수업의 실제 버튼은 ‘비교에 담기’, ‘비교한 두 원문 저장’, ‘실험 A/B’ 선택, ‘두 저장 원문 열기’, ‘A 명시 재계산’, ‘B 명시 재계산’이다. 단일 ‘원문 저장’과 A/B 두 재현 자료 저장을 혼동하지 않는다.

정상 종료 뒤 새 프로세스에서 두 저장 자료를 열면 결과는 NOT_PRODUCED다. A만 요청하면 B는 미생산으로 남는다. B 계산 뒤 A 원본과 새 결과가 보존되는지 확인한다. 저장 자료에는 과거 보고서·성공JSON·Proof를 넣지 않는다. 입력이 원문에 적히므로 A/B의 전체 SourceSnapshot bytes·SHA가 다를 수 있다. 같은 모형·정확 의존과 속도 하나 차이의 결속을 사용한다.

## 대표 오류와 수정

| 원문·상태 | 설명과 다음 행동 | 근거 범위 |
|---|---|---|
| `길이기준 <- 1@m + 1@s.` | ‘단위 차원이 다릅니다: m vs s’. `길이기준 <- 1@m.` 복원 | R009 실제 Native 거부. standalone fixture의 위치는9:9이며 rooted main의 위치로 복사하지 않음 |
| A만 저장 성공 | 둘 다 완료라고 하지 않는다. A 정상본을 보존하고 실패 상태를 확인 | 기존 M6 부분 실패 근거 재사용. 실제 pair CAS·정전 주입은 NOT_RUN |
| 재열기만 수행 | 오류가 아니라 아직 미생산. A/B 각각 명시 재계산 | R009 Chrome cold 관측 |
| 계산 중 편집·작품 전환 | 늦은 응답을 새 원문의 답으로 쓰지 않는다 | R009 실제 Worker 지연·편집/전환 관측 |
| 속도 외 조건 변경 | 속도만 다른 비교가 아니다. 원문·단위·표본·목표·의존 확인 | 해당 비교 조건. 다른 실험 자체를 언어 오류라고 일반화하지 않음 |

속도0·목표1은 비유일, 속도0·목표7은 해 없음이라는 모형 설명은 가능하다. 이 후속 교재 작업에서 추가 과제를 새로 실행한 것은 아니다. 첫 모형의 t>=0와 정규 단위 기준 크기1 범위를 일반 수학·전체 단위 체계의 제한으로 확대하지 않는다.

기준 SOURCE f7d9f2fd4d2ec3991e3182a1df75646b212fae48, TREE d66a86f6c6bd99bfff7564369637187cb2658335. R009의 Native/Node 생산자·실제 Chrome 계산/세 보기/A/B 저장·cold·각 명시 재계산은 dev 작성자 근거로 재사용한다. 교재의 별도 독립 실행 PASS가 아니다.
