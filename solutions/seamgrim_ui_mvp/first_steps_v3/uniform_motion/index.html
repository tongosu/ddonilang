속도가 달라지면 언제 도착할까?

처음 위치1 m에서 일정한 속도로 움직입니다. 속도만 바꾸면 같은 시각의 위치와 목표까지 걸리는 시간이 어떻게 달라질까요?

학생 첫걸음 · 교사용 해설

실험 A

작품 뿌리 · 계산 원문

  1. 셈그림 첫걸음의 ‘등속운동 · 속도와 도달 시간’을 내 작업으로 보관하고 ‘탐구 노트’에서 ‘계산’을 누릅니다.
  2. 시각0·2·4초에서 위치1·4·7 m를 확인합니다. ‘표’·‘그래프’·‘위치’의 같은 시각을 대조합니다.
  3. 목표7 m의 도달 시간4초를 원식에 넣어 확인하고 ‘비교에 담기’를 누릅니다.

실험 B: 한 줄 바꾸기

노트를 닫고 main.ddn의 속력:나눔수 := 3 / 2.만 속력:나눔수 := 2.로 고칩니다. 수정 원문 저장 후 다시 계산하고 비교에 담습니다. 수정 후 원문과 대조할 수 있습니다.

B의 위치는1·5·9 m이고 목표 도달 시간은3초입니다. 처음 위치·표본 시각·목표·단위 기준은 유지합니다. 같은 축 숫자로 두 실험을 비교하세요.

저장하고 새로 계산하기

  1. ‘비교한 두 원문 저장’을 누르고 두 저장의 완료를 확인합니다. 브라우저와 Native를 정상 종료합니다.
  2. 새로 실행한 작업대의 탐구 노트에서 ‘실험 A’와 ‘실험 B’를 각각 고르고 ‘두 저장 원문 열기’를 누릅니다. 두 결과는 NOT_PRODUCED입니다.
  3. ‘A 명시 재계산’을 누르면 A만 계산합니다. 이어 ‘B 명시 재계산’을 누르고 두 새 결과를 비교합니다.

보존한 것은 두 재현 원문이며 과거 결과가 아닙니다. 새 결과를 저장 당시 관측으로 표시하지 않습니다. 한쪽 실패를 두 실험의 성공으로 세지 않습니다.

잘못된 단위 실험

별도 오류 실험에서 길이기준 <- 1@m + 1@s.로 바꾸면 ‘단위 차원이 다릅니다: m vs s’로 거부됩니다. 원래 길이기준 <- 1@m.으로 되돌립니다. 고정 거부 원문은 실제 CLI 진단을 확인한 참고 입력이며 Native 작품 뿌리와 혼동하지 않습니다.
