# 속도가 달라지면 언제 도착할까?

## 처음 위치와 속도

물체가 직선 위에서 일정한 속도로 움직입니다. 처음 위치는1 m, 속도는3/2 m/s입니다. 3/2는1.5와 같은 수이지만 이 실험에서는 분수 그대로 계산합니다. 시각은0초 이상이고, 가속도·마찰·충돌은 다루지 않습니다.

위치는 ‘처음 위치 + 속도 × 지난 시간’입니다. 2초 동안3 m를 이동하므로 위치는4 m입니다. 4초에는6 m를 이동해7 m에 있습니다. 이동한 거리와 처음 위치를 포함한 현재 위치를 구별하세요.

## 실행하고 세 가지 보기 읽기

1. 셈그림 첫걸음에서 ‘등속운동 · 속도와 도달 시간’을 열고 내 작업으로 보관합니다. 작품은 root.ddn과 main.ddn으로 구성됩니다.
2. main.ddn의 처음·속력·목표를 읽습니다. ‘탐구 노트’를 열고 ‘계산’을 누릅니다.
3. ‘표’에서 아래 값을 확인하고 ‘그래프’·‘위치’로 바꾸어 같은 시각을 읽습니다.

| 시각(s) | 위치(m) |
|---|---|
| 0 | 1 |
| 2 | 4 |
| 4 | 7 |

그래프의 가로축은 시각, 세로축은 위치입니다. 위치 그림은 각 시각의 위치를 같은 눈금에서 보여 줍니다. 세 보기는 같은 계산 결과입니다. 확대하거나 가로로 이동해도 정확한 표의 값은 달라지지 않습니다.

목표7 m에 도달하는 시간은4초입니다. 원래 식에 넣으면 `1 + (3/2) × 4 = 7`입니다. 이 대입 검산은 이 모형의 계산 확인이지 별도의 수학 증명 발급이 아닙니다.

## 속도만 바꾸기

1. 첫 결과를 ‘비교에 담기’로 남깁니다. 이것이 실험 A입니다.
2. 노트를 닫고 main.ddn의 한 줄만 바꿉니다.

```ddn
    속력:나눔수 := 3 / 2.
```

바꿀 줄:

```ddn
    속력:나눔수 := 2.
```

3. 수정 원문을 저장하고 노트를 다시 열어 ‘계산’을 누른 뒤 ‘비교에 담기’를 누릅니다. 이것이 실험 B입니다. 처음 위치·목표·시각·단위 기준은 바꾸지 않습니다.

| 시각(s) | A 위치(m) | B 위치(m) |
|---|---|---|
| 0 | 1 | 1 |
| 2 | 4 | 5 |
| 4 | 7 | 9 |

B의 목표 도달 시간은3초입니다. `1 + 2 × 3 = 7`로 확인합니다. 두 그래프의 같은 축 숫자를 읽어 보세요. 같은2초 동안 A는3 m, B는4 m 이동합니다. 화면에서 선이 더 가파르다는 인상만으로 답하지 않습니다.

## 두 실험을 저장하고 다시 계산하기

1. 두 결과를 비교에 담은 뒤 ‘비교한 두 원문 저장’을 누릅니다. 두 재현 원문의 저장 완료를 확인합니다. 하나만 성공하면 둘 다 저장된 것이 아닙니다.
2. 브라우저와 Native 작업대를 정상 종료합니다. 다시 실행해 탐구 노트를 엽니다.
3. ‘실험 A’와 ‘실험 B’의 목록에서 해당 저장 작품을 각각 고르고 ‘두 저장 원문 열기’를 누릅니다. 둘 다 `NOT_PRODUCED`, 즉 아직 결과가 없는 상태입니다.
4. ‘A 명시 재계산’을 누릅니다. A는1·4·7 m입니다. 아직 요청하지 않은 B는 결과가 없어야 합니다.
5. ‘B 명시 재계산’을 누릅니다. B는1·5·9 m이고 A 결과는 남아 있습니다. 표·그래프·위치로 두 새 결과를 비교합니다.

저장하는 것은 모형 원문·입력·단위·표본·가정·정확한 의존 판본을 포함한 재현 자료입니다. 새 결과는 지금 다시 계산한 값이지 과거 결과를 꺼낸 것이 아닙니다. 과거 결과 자체의 영속 보관은 후속 기능입니다. 이 저장은 실행 세계의 이어 실행도 아닙니다.

## 단위가 다른 값을 더하면?

기본 원문을 보존한 별도 오류 실험에서 다음 줄을 바꾸어 봅니다.

```ddn
    길이기준 <- 1@m + 1@s.
```

1 m와1초는 차원이 달라 더할 수 없습니다. 대표 진단은 ‘단위 차원이 다릅니다: m vs s’입니다. 원래 줄 `길이기준 <- 1@m.`으로 되돌리세요. 화면의 단위 글자를 m로 바꾸는 것으로 해결되지 않습니다.

한쪽 계산이 실패하거나 아직 실행하지 않았다면 그 상태를 남깁니다. 계산 중 원문·작품을 바꾼 경우에는 현재 원문을 확인하고 다시 명시 계산합니다. 이전 성공 결과로 빈칸을 채우지 않습니다.

## 더 생각하기

처음 위치는 같고 속도만 다른 두 물체가 왜0초에는 같은 위치에 있을까요? 표와 식으로 설명해 보세요. 속도를0으로 바꾸면 목표가 처음 위치일 때와 아닐 때 어떤 차이가 있을까요? 이 추가 과제는 기본 A/B 비교를 마친 뒤 별도로 시도합니다.
