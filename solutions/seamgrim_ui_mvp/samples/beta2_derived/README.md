# 값이 바뀌면 함께 계산되는 값

베타2 개발판의 잠정 `<<-` 예제입니다. 아직 베타1에서 실행하는 예제가 아닙니다.

`원천`은 바꿀 수 있는 세계 값이고, `결과`는 그 값의 두 배입니다. 원천이 2, 3, 4로 바뀌면 결과도 4, 6, 8로 계산됩니다. `결과 <- 10.0.`처럼 파생 대상에 직접 쓰면 오류입니다.

저장한 뒤 다시 열어도 관계는 원문에서 읽습니다. 저장된 결과와 다시 계산한 결과가 다르면 복구가 필요하다고 거부합니다. 저장된 값을 그대로 믿거나 다른 값으로 대신하지 않습니다.

실험해 보세요.

1. `2.0`을 `3.0`으로 바꾸면 어떤 결과가 나올지 예상합니다.
2. 원천과 결과의 현재 값을 비교합니다.
3. 일시정지한 뒤 저장하고 작업대를 닫습니다.
4. 같은 작업대에서 다시 열고 한 마디 진행해 관계가 유지되는지 봅니다.

공통 Rust·CLI 세 이름·WASM에서는 같은 식의 저장3+이어 실행4=연속7, 재저장7+이어 실행1=연속8을 대조했습니다. 이 예제 폴더의 줄바꿈·표현까지 포함한 새 배포 ZIP과 실제 작업대 검사 결과는 별도 배포 기록을 확인하세요. 개발판 전체 완료나 장애 복구 보증을 뜻하지 않습니다.
