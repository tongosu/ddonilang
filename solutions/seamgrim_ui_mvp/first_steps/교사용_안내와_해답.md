# 정의 중심 첫걸음 교사용 안내와 해답

학생이 규칙을 정의하고 직접 호출하는지를 확인하는 10차시 지도안이다. 학생용 본문은 README.md, 차시당 원문4개는 예제 폴더에 있다. 수정실습10개와 오류 교정5개를 별도로 제공한다. 보충2개를 포함한 총57개는 정상 실행52개와 의도한 오류5개로 나뉜다. 의도한 오류는 07D_핀중복오류 및 08A부터08D까지이며 07D를 정상 실행 대상으로 세지 않는다. 이 안내는 수업 준비 자료이며 실제 학생 수업을 검증한 결과가 아니다.

## 공통 수업 흐름

1. 설명과 원문 읽기: 새 표면을 하나씩 짚는다.
2. 예상: 실행 전에 출력 또는 거부 이유를 적는다.
3. 실행: 원문 그대로 CLI 또는 v25 셈그림 문서에서 실행한다.
4. 수정: 한 조건이나 값을 바꾸고 다시 예상한다.
5. 해설: 어떤 정의의 어떤 받는자리와 결과자리가 관련되는지 말한다.

수업 시간은 학급에 맞춰 조절한다. 예제를 읽는 학생에게 예상 답을 바로 보여 주지 않는다. 오류 예제에서는 오류 코드를 외우게 하지 말고 가르치려던 실수가 잡혔는지를 확인한다.

## 흔한 오해를 막는 설명

- `:=`는 정의, `<-`는 보통 결속·다시결속과 결과자리 배정이다. 처음 결속을 무조건 `:=`로 쓰게 하지 않는다.
- 셈씨는 계산, 움직씨는 효과가 있는 동작을 나타낸다. 움직씨도 결과를 낼 수 있으므로 결과 있음과 없음만으로 구별하지 않는다.
- 조사형 호출의 인자 묶음 괄호는 필수가 아니다. `7의 두배 보여주기.`처럼 간단하게 읽되, 밑변·높이처럼 역할이 다른 값에는 `(밑변=8, 높이=5) 삼각형넓이 보여주기.`를 사용한다. 조사를 붙일 수 있다는 것과 자연스럽게 읽힌다는 것을 혼동하지 않는다. 02C·02D에서 이름 핀을 배우고, 08D에서 의도한 조사 모호함과 그 교정을 따로 확인한다.
- `실행`은 이 수업에서 작성자가 고른 정의 이름이다. 한 파일 예제는 마지막 줄의 호출로 실행하며, 파일 이름이나 첫 정의를 자동 시작점으로 가르치지 않는다.
- 정의 안에서 순회하거나 지역 결속을 바꾸는 것과 세계에 동작을 게시하는 것은 같은 일이 아니다.
- 조건 갈래에서는 필요한 결과자리를 배정한다. 마지막 식을 자동 결과라고 가르치지 않는다.
- `-->`는 받는 씨와 내는 씨의 관계를 나타내는 함수 형 표시이고, `:=`가 이름 있는 정의를 만든다(RD-376·RD-407). 단일식 셈씨라는 설명은 선언 전체에 해당하며 `-->` 기호만의 역할이 아니다. 본문형을 이해한 뒤 보충으로 소개한다.
- 지금 상점 예제는 구매 가능 여부와 잔액을 출력한다. 지갑 저장·상태 영속화·실시간 입력을 제공하지 않는다.

## 제품 제한과 판정 범위

본문 안의 빈 `차림[]` 생성은 현재 파서가 거부한다. 06C는 한 원소 차림의 합을 배우는 실습이며 빈 차림 지원의 대용 검사라고 주장하지 않는다. 빈 차림을 배우는 정상 실습이 필요하면 지원 표면을 먼저 확정·구현·검증해야 한다. 이 코스를 위해 새 표면이나 라이브러리를 만들지 않았다.

원문 이름에 호출 꼬리 `기`를 붙인 큰값고르기 초안은 현재 파서에서 거부돼 선언 이름을 큰값으로 정리했다. 원문이 받는 실제 표면을 가르치되, 이 코스로 SSOT의 이름 정책을 새로 확정하지 않는다.

검증목록의 기대값은 손 계산과 명시 규칙에서 정했다. 원문을 실행한 출력으로 기대값을 복사하지 않았다. 본문40개·교정5개·수정10개·보충2개는 실제 CLI 세 이름과 WASM으로 검사한다. 구체적 실행·PDF·ZIP 검증 결과는 수정판 보고를 따른다. 학생 이해도와 독립검토는 이 검사로 대신하지 않는다.
