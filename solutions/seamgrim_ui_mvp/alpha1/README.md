# 또니랑 알파1 빠른 시작

이 폴더의 네 `.ddn` 파일은 공식 또니랑 제품 경로에서 직접 실행되는 작은 프로그램이다. 숫자와 입력 목록을 바꾼 뒤 다시 실행해 볼 수 있다.

네 예제는 모두 한 번 계산하고 끝나는 일반 프로그램이다. 셈그림에서도 출력이 계속 반복되지 않는다. `04_시간단계_시뮬레이션.ddn`은 네 시간 단계만 계산한다. 매 마디 계속 움직이는 시뮬레이션과는 구분한다.

## 첫 실행

```text
또니랑 실행 solutions/seamgrim_ui_mvp/alpha1/01_요금_계산기.ddn --source-profile v1-core-v25
```

`ddonirang`, `ddonilang`, `또니랑` 세 이름에서 같은 명령 형식을 쓴다.

## 예제

- `01_요금_계산기.ddn`: 조사 호출과 `금액=원요금` 형태의 이름 있는 인자, 호출 결과의 산술·다른 호출 전달을 보여준다. 기대 출력은 원요금 `2800`, 25% 할인 뒤 `2100`이다. `사용량`에 글을 넣으면 타입 오류로 실행되지 않는다.
- `02_조건과_반복.ddn`: 목록을 반복하며 제곱을 구하고, 조건에 따라 크기를 표시하고, 합계를 상태로 갱신한다. 기대 마지막 출력은 `30`이다. `입력들`에서 숫자 대신 글을 넣으면 목록 원소 타입 오류가 난다.
- `03_자동_함수표.ddn`: 입력 목록의 각 값을 셈씨에 전달하고, 결과를 다음 셈씨가 소비해 함수 표를 만든다. 목록을 고치면 표의 행 수가 함께 바뀐다. 필수 `값` 인자를 지우면 누락 인자 오류가 난다.
- `04_시간단계_시뮬레이션.ddn`: 위치와 속도를 두 셈씨로 계산하고 최상위 상태에 반영한다. 기대 위치는 차례로 `2, 5, 9, 14`다. 시간간격에 글을 넣으면 타입 오류가 난다.

## 정의와 호출

`셈씨`는 결과 타입과 같은 이름의 결과자리에 값을 넣는다. 예를 들어 `제곱:수:셈씨`는 끝나기 전에 `제곱 <- ...`을 실행해야 한다. 조사가 있는 호출은 `(값~을) 제곱하기`, 이름 있는 호출은 `(값=3) 제곱하기`처럼 쓴다.

호출 결과는 변수에 묶거나 산술식과 다른 호출에 바로 전달할 수 있다. 중첩 호출마다 지역변수와 결과자리는 분리된다.

## 오류를 읽고 고치기

- `E_CALL_REQUIRED_PIN_MISSING`: 필요한 인자가 빠졌다. 정의 머리의 핀 이름이나 조사를 확인한다.
- `E_PARSE_CALL_PIN_DUPLICATE`: 같은 핀에 두 값을 넣었다. 중복 인자를 하나 지운다.
- `E_PARSE_CALL_JOSA_AMBIGUOUS`: 같은 조사가 여러 핀을 가리킨다. `값=...` 이름 형식으로 분명히 쓴다.
- `E_RUNTIME_TYPE_MISMATCH`: 정의가 요구한 타입과 실제 값이 다르다.
- `E_RESULTPLACE_UNASSIGNED`: 결과가 필요한 셈씨가 결과자리를 채우지 않고 끝났다.

오류가 나면 원문을 고친 뒤 같은 실행 명령을 다시 사용한다. 셈그림에서는 편집기에 원문을 붙여넣고 실행한 뒤, 진단에 표시된 부분을 고쳐 다시 실행한다.

`잘못된입력/`에는 위 오류를 직접 재현하는 원문이 있다. 파일 이름의 문제를 고쳐 같은 명령으로 다시 실행하면 된다.

## 현재 지원하지 않는 범위

테트리스 전체, 이중 진자 전체, 신규 DDL·다국어 표면, 고급 증명, NuriGym, 자기호스팅, 새로운 저장·Tensor·identity 계약은 알파1 범위가 아니다.
