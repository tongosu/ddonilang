V2 첫걸음교사용

도우미가 바뀌어도 내 작품의 답은 그대로일까?

두 작품이 같은 도우미를 쓰고 있습니다. 도우미의 새 판본이 나왔다고 두 작품의 답이 모두 저절로 바뀌어도 될까요? 이 수업에서는 각 작품이 선택한 판본과 명시적인 갱신을 구별합니다.

도우미 하나 만들기

셈그림 공식 모음에서 V2 첫걸음 · 고정 도우미 판본 만들기를 열고 내 작업으로 복제합니다. 실행 결과는 7입니다. lib/helper.ddn은 다음 값을 공개합니다.

(속도=속도) 드러냄.
속도:수 := 7.

이 예제의 속도는 단위가 없는 수입니다. 이름만 보고 m/s가 붙은 물리량으로 해석하지 않습니다.

프로젝트 파일에서 lib/helper.ddn을 선택하고 ‘가지로 묶기’를 엽니다. 이름 운동, 판본 1.0.0과 발행 주체를 확인해 미리보기한 뒤 발행합니다. 기존 선반에 같은 이름이 있다면 교사가 분리한 실습 선반을 사용하세요. 다른 사람의 판본을 덮어쓰지 않습니다.

A와 B가 판본을 선택하기

V2 첫걸음 · A/B를 따로 갱신하기를 두 번 복제해 서로 다른 내 작품 A와 B를 만듭니다. 설치 전 기본 원문의 출력1은 설치 성공을 뜻하지 않습니다. 첫 Native 저장 전에 가지 선반에서 운동1.0.0을 별칭 힘으로 각각 설치합니다.

A의 app/main.ddn은 다음 원문을 사용합니다. B에서는 힘.속도 뒤에 + 1을 넣습니다.

(힘=힘) 쓰임.
앱:움직씨 := { 힘.속도 보여주기. }.

설치가 만든 root·잠금 자료·vendor 파일은 유지합니다. 새 실행해 A=7, B=8을 확인합니다. 파일을 직접 복사해 설치를 흉내 내지 않습니다.

한 작품만 갱신하기

생산자의7을9로 바꾸고 운동2.0.0을 새로 발행합니다. 발행만 한 상태에서 A와 B는 무엇을 출력할지 먼저 예상하세요.

단계AB바꾼 것
각각1.0.0 선택78처음 설치
2.0.0 발행만78선반에 새 판본 추가
A만2.0.0 갱신·새 실행98A의 선택 판본
B도2.0.0 갱신·새 실행910B의 선택 판본

A에서 갱신 미리보기·적용을 명시합니다. 원문 저장과 새 실행은 각각 확인합니다. B가 바뀌지 않았는지 확인한 뒤 B도 명시 갱신합니다. 그림이나 과거 출력이 남아 있는 것을 새 실행 결과로 세지 않습니다.

이 통합 후보는 r187의 저장된 A/B 가지 갱신 교정과 실제 실행 근거를 인수했습니다. Native 저장과 새 실행은 각각 명시적으로 합니다. r176만 있는 과거 실행물에는 이 교정을 소급하지 않습니다. 이번 교육 연결의 독립검토·학생 확인은 별도입니다.

저장하고 다시 열기

원문 저장과 세계 저장의 성공을 각각 확인합니다. 브라우저와 Native를 정상 종료하고 새 프로세스에서 A와 B를 다시 엽니다. 선택 판본·원문을 먼저 확인하고 명시적으로 이어 실행합니다. 이 수업은 전체 기록 되감기나 자동 판본 갱신을 요구하지 않습니다.

일부러 잘못된 자료 읽기

자기 저장본을 손상시키지 말고 교사용 분리 실습 사본을 씁니다.

  • 설치한 helper artifact가 없으면 E_GAJI_ARTIFACT_SOURCE_MISSING으로 거부됩니다. 실제 작성 frontdoor의 거부이며 Native 저장까지 도달했다는 뜻은 아닙니다.
  • 현재 vendor 해소와 맞지 않는 lock은 E_LOCK_HASH_MISMATCH로 거부됩니다. 올바른 고정 자료를 명시적으로 다시 선택합니다. lock 해시를 손으로 고쳐 통과시키지 않습니다.
  • 브라우저는 그보다 먼저 원문 불일치를 E_SOURCE_SAVE_FAILED/E_NATIVE_SOURCE_SOURCE_CHANGED로 거부할 수 있습니다. 이를 lock 검사 통과나 실행 실패로 바꾸어 설명하지 않습니다.

정상본을 다시 선택하고 저장 연결을 확인한 뒤 재열기합니다. 실패한 저장이 성공으로 표시되거나 기존 정상본이 바뀌면 수업을 멈추고 교사에게 알립니다.

CLI에서 고정 자료 확인하기

교사가 지정한 V2 프로그램을 쓰는 터미널에서 이 교재 폴더로 이동합니다. 아래의 또니랑은 그 프로그램을 가리켜야 합니다. RC1이나 다른 실행물이 대신 선택되지 않도록 확인합니다.

또니랑 작품자료 실행 ".\fixed_helper\작품.json" --마디수 3

이 자료는 설치된 도우미와 마디 횟수를 함께 출력하는 기존 검사 작품입니다. 출력 줄은 차례로 7, 1, 7, 2, 7, 3입니다. A/B의 두 작품을 실행한 결과가 아니라 한 고정 의존 작품의 세 마디 결과입니다. 브라우저의 판본 설치·갱신 조작과 구별하세요.
