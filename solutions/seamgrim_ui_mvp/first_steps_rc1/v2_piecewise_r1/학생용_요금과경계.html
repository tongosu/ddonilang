조건별 요금교사용

사용량이 경계를 넘으면 요금은?

사용량3까지는 한 단위에10, 그 뒤6까지는 추가 한 단위에20을 받는 작은 요금표를 만듭니다. 사용량4의 요금은40일까요,80일까요,아니면 다른 값일까요?

이번 숫자는 단위 없는 수업용 값입니다. 실제 원화나 특정 회사의 요금제가 아닙니다. 현실의 고정요금·세금·할인 등은 넣지 않았습니다.

두 계산 규칙 읽기

요금 (사용량:나눔수~을 --> 나눔수) := 조건별 {
정의역: 0 <= 사용량 <= 6.
10 * 사용량 : 0 <= 사용량 <= 3.
30 + 20 * (사용량 - 3) : 3 < 사용량 <= 6.
}.

((사용량=4) 요금) 보여주기.

정의역은 이 요금 함수에 넣을 수 있는 입력 범위입니다. 각 행에서 콜론 왼쪽은 계산식, 오른쪽은 그 식을 쓸 조건입니다. 나눔수는 정확한 분수 계산을 할 수 있는 씨입니다.

사용량4에서는 앞의3에30, 추가1에20을 내므로 합계50입니다. 전체 사용량4에20을 곱한80이 아닙니다. 출력 50/1은 정확한 분수로 나타낸50입니다.

먼저 실행하기

제공 원문을 읽고, 교사가 지정한 V2 실행물을 쓰는 터미널에서 교재 폴더로 이동합니다.

또니랑 실행 계산/요금계산.ddn --글판 v1-core-v25 --마디수 1

예상 계산 출력은 50/1입니다. 원문을 다른 언어로 바꾸지 않고 같은 조건별 정의를 실행합니다.

호출의 숫자 한 곳 바꾸기

마지막 줄의 사용량=4만3으로 바꿉니다. 두 구간이 만나는3에서 어느 행을 선택해야 할까요? 실행 전에 답하고 30/1인지 확인하세요. 다음에는6으로 바꾸어 90/1을 확인합니다.

입력선택하는 조건계산기대 출력
30≤사용량≤310×330/1
43<사용량≤630+20×150/1
63<사용량≤630+20×390/1
7정의역 밖계산 결과를 발급하지 않음거부

확인용 사본: 경계3 · 경계6 · 입력7. 같은 함수를 새로 만드는 대신 입력 조건을 비교합니다.

경계가 두 행에 걸리면?

분리한 실습 사본에서 둘째 행의 3 < 사용량을 3 <= 사용량으로 바꿔 보세요. 입력3이 두 행에 모두 들어갑니다. 두 식이 우연히30으로 같아도 조각이 겹치므로 거부됩니다.

반대로 첫 행 끝을 사용량 < 3으로 바꾸고 둘째 행도 3 < 사용량으로 두면3에 적용할 행이 없습니다. 이 경우도 정의역을 덮지 못해 거부됩니다.

겹침의 수정은3을 첫 행에만 포함하는 원래 조건으로, 빈틈의 수정은 빠진3을 첫 행에 포함하는 원래 조건으로 되돌리는 것입니다. 행의 순서를 바꾸어 먼저 만나는 것을 고르게 하는 방식으로 고치지 않습니다.

겹침 원문 · 빈틈 원문은 기존 거부 사례 사본입니다. 거부할 예제를 실패했다며 지우지 말고, 어떤 조건이 잘못됐는지 설명하세요.

현재 지원 범위

유한 개의 정확한 유리수 구간과 지원되는 값식의 조건별 계산입니다. 임의의 모든 조건·효과·호출·외부 값 사용을 지원한다는 뜻이 아닙니다. 조건 검사를 통과했다고 형식 Proof가 발급되는 것은 아닙니다. 미지원은 참이나 해 없음으로 바꾸지 않습니다.
