조건별 요금교사용

같은 요금 계산을 저장하고 이어가기

요금 함수를 매마디 부르는 작품을 저장하고 다시 엽니다. 요금의 입력과 실행한 마디 횟수를 구별해 읽어 보세요.

작품 열기

기존 조건별 요금 작품을 V2 셈그림 ‘가져오기’로 엽니다. root.ddn과 app.ddn을 함께 보존합니다. 원문에는 앞 수업과 같은 조건별 요금 정의와 다음 실행 부분이 있습니다.

채비 { 횟수:바른수 := 0. 결과:나눔수 := 0. }.
앱:움직씨 := { (매마디)마다 {
  횟수 <- 횟수 + 1.
  결과 <- (사용량=3) 요금.
  결과 보여주기.
  횟수 보여주기.
}. }.

이번 고정 작품은 사용량3을 계산합니다. 첫 수업의 입력4·결과50/1과 다릅니다. 여기서 횟수가4가 되어도 사용량이4로 바뀐 것은 아닙니다.

두 마디를 보관하기

  1. 원문 저장의 성공을 확인하고 명시 실행합니다.
  2. 두 마디를 진행하고 멈춥니다. 현재 결과는30/1, 횟수는2여야 합니다.
  3. 현재 세계 저장의 성공을 확인합니다. 원문 저장만 한 것으로 세계를 저장했다고 세지 않습니다.
  4. 브라우저와 Native 작업대를 정상 종료합니다.

새 프로세스에서 두 마디 더 진행하기

  1. 다시 시작해 ‘내 작업’에서 같은 작품을 엽니다.
  2. 선택한 원문과 저장된 세계를 확인한 뒤 명시적으로 이어 실행합니다.
  3. 두 마디 더 진행하고 멈춥니다. 현재 요금30/1, 횟수4를 확인합니다.

마지막 화면의 ‘출력30/1’과 ‘출력4’는 요금과 횟수입니다. 같은 요금을 네 번 더한 총액120이 아닙니다. 저장 전2마디와 재열기 뒤2마디의 상태를, 처음부터 연속4마디 진행한 결과와 대조할 수 있습니다.

한 조건 더 실험하기

분리한 사본에서 호출의 사용량=3만4로 바꾸면 요금은50/1이어야 합니다. 수정 원문을 저장하고 새 실행하세요. 이전 원문의 세계를 그대로 이어 계산한 것으로 설명하지 않습니다. 이 추가 편집의 실제 교육 UI 경로는 최종 연결 후 확인할 과제입니다.

그림보다 실제 값을 읽기

이 수업은 계산 출력과 저장·이어 실행을 다룹니다. 그래프가 나왔다거나 선이 움직였다는 사실로 요금이나 저장 성공을 판단하지 않습니다. 표시 언어를 바꾸어도30/1·횟수·실행 세계는 그대로여야 합니다.

원문 오류·잘못된 저장 자료가 거부되면 성공한 값처럼 표시하지 않고 이전 정상본을 보존합니다. 오류 안내가 가리키는 원문과 실제 선택한 저장본을 확인하세요.

지원과 확인 범위

지정된 Native/WASM 계산과 실제 브라우저·새 프로세스 이어 실행 근거를 재사용합니다. 화면 수정의 기준 소스와 계산 실행물을 빌드한 소스는 다릅니다. 전체 자원 envelope 일치나 모든 플랫폼·학생 확인을 완료했다고 하지 않습니다.
