안내와 원문의 언어를 구분하기

기존1·17·29·30차시를 재사용한다. 첫 예제는 기존01A의7 출력, 두 번째는 r188의0 출력·원문/세계 저장과 실패 안내 작품이다. 원문 언어를 새로 만들거나 같은 작품을 일본어로 다시 작성하지 않는다.

학생이 표시만 다른 두 화면의 같은 원문·계산값을 가리키게 한다. 변경된 문구를 많이 찾는 것이 목적이 아니다. 저장 중에는 원문 저장/세계 저장/실패의 종류가 보존되고, locale 전환만으로 실행·저장 요청이 발생하지 않는 것이 핵심이다.

r188은 fe48eea2 결합판에서 source_save/world_save/failed_save/cold_reopened_locale 작성자 검사를 수행했다. locale-only POST0, 원문·실행·frame 보존, 파서 거부 뒤 이전 VM·읽을 수 있는 저장 파일6개 불변, 새 프로세스 원문 재열기와 CLI3 대응을 재사용한다. 세 이름의 독립3회 컴파일·전체V2·학생/독립 PASS로 확대하지 않는다.

CLI는 r159 실제 지원과 이후 소스 동일성 근거를 사용한다. 전역 옵션은 명령 앞에서만 읽는다. 명시 ko/ja가 우선이며 선택하지 않은 하위 환경값을 오류 원인으로 쓰지 않는다. TTY에만 보조 일본어 안내가 붙는 범위가 있고 redirected stdout/stderr·기계 코드/범위는 보존한다. 프로그램의 한국어 출력 문장도 자동 번역하지 않는다.

실습 실패는 학생 정상본이 아닌 분리한 사본에서 만든다. 닫는 중괄호를 복원해 원문을 고치고, 저장 실패의 기존 정상본을 유지하는지 확인한다. 설정을 닫지 않아 저장 버튼을 가린 관측기 실패가 있었으므로 교사는 열린 선택 목록부터 닫게 한다. 실패를 회피하려고 강제 클릭이나 저장 우회를 하지 않는다.

구형r170의 모듈 검사·한정 독립판정과 r188의 실제 Native 결합은 별개다. 이번 교재의 새 카탈로그 연결과 학생의 복구 조작은 통합 후 변경 영향으로 확인한다. 원문과 실행물이 같은 기존 cold 전체 검사를 반복하지 않는다.

공통 표시/저장 UI는 dev writer다. 이 반환은 교육 HTML·동일 원문·목록 메타데이터만 제공한다. 일본어 원문/등록/DDL/확장07/V3 보존은 별도다. 실제 학생0/HUMAN_NOT_RUN, 물리 OS IME·원어민/Human·공개와 전체 기능 독립판정은 미완이다.
