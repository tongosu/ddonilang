교사용 해설

안내를 바꾸면 프로그램도 바뀔까?

같은 프로그램을 한국어 안내와 일본어 안내로 사용해 봅시다. 버튼과 도움말의 언어가 바뀌는 것과 프로그램 원문이 바뀌는 것은 다릅니다.

같은 계산을 두 안내로 실행하기

(3 + 4) 보여주기.

기존 첫 계산 원문을 읽으세요. 답을 예상한 뒤 교사가 지정한 V2 프로그램을 쓰는 터미널에서 이 교재 폴더로 이동해 실행합니다.

또니랑 --표시말씨 ko run 첫계산.ddn --source-profile v1-core-v25
또니랑 --표시말씨 ja run 첫계산.ddn --source-profile v1-core-v25

두 실행의 계산 출력은 모두7입니다. 일본어를 선택했다고 숫자7이나 보여주기가 번역되는 것이 아닙니다. 정상 실행에서 번역할 안내가 없으면 화면이 같을 수 있습니다.

도움말 차이는 다음처럼 확인합니다. 일본어 도움말에도 아직 번역하지 않은 기존 한국어 안내가 함께 남을 수 있습니다.

또니랑 --표시말씨 ko --help
또니랑 --표시말씨 ja --help

--display-language는 같은 옵션의 영어 철자입니다. 두 철자를 함께 중복 지정하지 않습니다. 옵션은 run 같은 명령 앞에 둡니다. --source-profile은 원문 해석 조건이므로 표시 언어 옵션으로 대신할 수 없습니다.

셈그림에서도 같은 작품 읽기

기존 저장 안내 실험 작품을 V2 셈그림의 ‘가져오기’로 엽니다. 프로젝트 파일 app/main.ddn을 읽습니다.

실행:움직씨 := {
  값:수 := 0.
  값 보여주기.
}.
  1. 상단 ‘표시 언어’를 열고 한국어를 선택합니다. 열린 설정 목록은 닫습니다.
  2. 원문을 저장하고 명시적으로 실행해 출력0을 확인합니다.
  3. 표시 언어를 일본어로 바꿉니다. 원문·출력·현재 실행은 그대로여야 합니다. 언어를 바꿨다는 이유로 다시 실행하거나 저장하지 않습니다.
  4. 원문 저장과 현재 세계 저장의 안내를 구별합니다. 표시 언어를 바꿔도 원래 저장 종류가 바뀌어서는 안 됩니다.
  5. 한국어로 돌아와 같은 원문과 값을 확인합니다.

CLI의 표시 언어 설정과 브라우저 선택은 자동으로 동기화되지 않습니다. 일본어 버튼을 선택해도 이 작품은 여전히 한국어 원문입니다. 일본어 DDN 작성·DDL은 이 수업의 범위가 아닙니다.

실패 안내는 성공으로 바뀌지 않는다

정상본을 저장한 뒤 분리한 실습 사본에서만 기존 오류 원문과 비교합니다. 마지막 닫는 중괄호가 빠진 원문입니다. 원문 저장이 거부되면 언어만 바꿔 보세요.

기대는 E_SOURCE_SAVE_FAILED 실패를 유지하는 것입니다. 일본어 안내가 붙어도 저장 성공이 되지 않으며 기존 정상 세계를 바꾸지 않습니다. 번역하지 않은 상세는 [ko]와 원래 진단으로 남을 수 있습니다.

원래 정상 원문으로 되돌리고 저장 안내를 확인합니다. 언어 변경을 ‘오류 수정’으로 사용하지 않습니다. 정상본 재열기는 실행하지 않은 상태를 확인한 다음 필요할 때 명시 실행합니다.

옵션을 잘못 적었다면

지원하는 값은 정확히 ko 또는 ja입니다. jp·대문자·값 누락·중복 지정은 입력 오류입니다. 옵션과 값을 한 번만 올바르게 적습니다. 원문 오류라면 표시 설정이 아니라 진단이 가리킨 원문을 고칩니다.

설정과 지원 범위

선택 순서는 명시 옵션 → DDN_DISPLAY_LANGUAGE 환경값 → 기본 한국어입니다. 이 수업은 영구 환경값을 바꾸지 않습니다. 터미널의 보조 안내와 파일로 돌린 기계 진단은 다릅니다. 프로그램 출력·오류 코드·원문 위치를 번역해 바꾸지 않습니다. 전체 진단 번역·일본어 원문 지원·원어민 확인을 완료했다고 하지 않습니다.
