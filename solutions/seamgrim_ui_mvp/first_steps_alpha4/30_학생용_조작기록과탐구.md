# 30차시 - 조작을 기록하고 다시 보기

이번 차시의 `수값`·`좌표값` 조회와 조작 순서 보존은 승인된 알파4 학습 범위입니다. `단계` 철자와 기록 이름·파일 머리표는 아직 잠정이며, 이전 테이프와 합칠지는 베타1 동결 때 정합니다.

## 설명

실행 중 값을 바꾸는 입력은 화면이 세계를 직접 고치지 않습니다. 조작을 마디의 InputSnapshot에 넣고, 또니랑 원문이 `입력사상.사건들`을 읽어 계산합니다. 수 사건에는 `수값`, 좌표 사건에는 `좌표값`이 있습니다. 끌기에는 시작·이동·끝 순서가 있으며, 잘못된 마디는 통째로 거부됩니다.

## 예상

같은 좌표와 반지름 기록을 느리게 재생하면 최종 공이 달라질까요? 확대 버튼만 눌렀다면 실행 입력 기록에 새 물리값이 필요할까요?

## 실행

1. 첫걸음 30A 또는 공식 모음의 “점과 반지름 · 조작 기록”을 엽니다.
2. ▶를 누르고 “입력 기록”을 펼칩니다.
3. 반지름 슬라이더를 움직이고 좌표판을 누른 채 끌었다 놓습니다. 측정값과 공의 위치·크기가 바뀌는지 봅니다.
4. 일시정지합니다. 마지막 조작이 아직 처리되지 않았다면 한 마디 진행합니다.
5. 기록 저장을 누릅니다. 실행을 닫은 뒤 같은 원문·입력 계약에 그 파일을 불러옵니다.
6. 마디별 세계 해시와 입력 해시가 같은지 고급 설정의 영수증에서 확인합니다.

CLI에서는 `조작입력재생 원문.ddn 기록파일 입력계약.json`을 사용합니다. 원문이나 계약을 바꾸면 같은 실행이 아니므로 기록을 거부할 수 있습니다. 알파1 기록과 잠정 V2 조작 기록을 섞지 않습니다.

## 수정과 종합 탐구

LRL 실험실을 엽니다. 원 운동과 타원 상황을 예상한 뒤 실행하고, 이심률과 섭동을 바꿔 명시적으로 다시 계산합니다. 위치 궤도, 속도 공간, LRL 벡터, 측정값을 함께 비교합니다. 섭동이 없을 때와 있을 때 LRL 보존이 어떻게 달라지는지 설명하세요.

공을 위로 끌면 원문에 초기 속도가 적힙니다(vx −3~3, vy 0.2~3). 현재 세계는 그대로입니다. ▶로 재실행해 궤도를 비교하세요. 상황 단추는 직접 발사 모드를 해제합니다.

`A검산오차`=A²−(1+2EL²)는 섭동=0에서만 0을 기대합니다. `방향변화`는 두 A의 주각(rad)이며 누적 세차가 아닙니다. A≈0이면 방향이 없으므로 `방향있음`도 읽으세요.

질량·중력계수가 1인 무차원 모형입니다. 계산은 매마디, 궤적 표본은 5마디마다입니다. 점 사이에서도 시간은 흐릅니다.

## 이유 설명

“저장한 상태로 이어가기”와 “입력 기록을 처음부터 재생하기”의 차이를 쓰세요. 같은 기록으로 결과가 같다는 사실만으로 모형이 실제 자연을 정확히 설명한다고 결론 낼 수 있을까요?

다음 표는 실행 전에 ‘예상’을 먼저 적고, 같은 마디까지 실행한 뒤 채우세요. 값을 바꾸면서 간격까지 함께 바꾸면 원인을 구별하기 어렵습니다. 한 번에는 조건 하나만 바꿉니다.

| 조건 | 예상 | 관찰한 A·방향 | 예상과 다른 점 |
| --- | --- | --- | --- |
| 원 운동, 섭동 0 | | | |
| 타원, 섭동 0 | | | |
| 타원, 섭동 0.02 | | | |
| 공을 끌어 새로 발사 | | | |

1. 섭동만 바꾼 두 실행에서 에너지·각운동량·A는 각각 어떤 차이를 보였나요? 처음 보존량의 수치와 실행 중 변화량을 구별해 설명하세요.
2. 같은 초기조건에서 간격만 반으로 줄였을 때 무엇을 비교해야 하나요? 계산 마디 수가 아니라 같은 모형 시간을 맞추세요.
3. 공을 끌고 재실행하기 전·후의 세계 해시는 어떻게 달랐나요? 화면 조작, 원문 편집, 실행 입력의 차이를 자신의 말로 적으세요.

기록 파일과 원문을 함께 보관하면 다른 사람에게 같은 실행을 보여 줄 수 있습니다. 그러나 자연을 설명하는 모형의 가정이 맞는지는 별도 문제입니다. 재현성과 물리적 타당성을 같은 말로 쓰지 마세요.
