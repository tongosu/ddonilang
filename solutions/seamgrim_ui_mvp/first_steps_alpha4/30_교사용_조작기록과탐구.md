# 30차시 교사용 - 입력 증거와 모형 검증

목표: 실제 조작 → 공통 Rust snapshot → 또니랑 계산 → 실제 파일 저장 → CLI/WASM 재생 흐름을 학생이 구별한다.

좌표판은 명시 범위 -5~5의 조작 값이고 화면 확대의 픽셀 이동과 다르다. 반지름은 계약의 범위·raw 격자 검증을 받는다. 값은 JS Number로 기록되지 않고 Rust Fixed64 raw 문자열로 결속한다.

채널별 초기 눌린 상태는 Control 전용이며 수·좌표 끌기 사건을 눌린 키로 바꾸지 않는다. 잘못된 시작/끝·순서·범위·기록 봉인을 수정해 성공한 척하지 않는다. 의도한 오류 활동으로 다른 원문에 기록을 불러오고 결속 오류를 읽게 할 수 있다.

골든은 검증한 실제 마우스 기록을 CLI 세 이름에 그대로 전달한 마디별 입력·세계 해시 비교다. 매번 다른 사람이 같은 마우스 궤적을 손으로 흉내 낸 결과를 같아야 한다고 요구하지 않는다.

LRL은 섭동0에서 보존량이다. 기본 타원 600마디 독립 RK4 비교의 성분 오차는 약2.7e-7, 에너지 변화는 약4e-9였다. 이 수치는 해당 초기조건·Fixed64·간격의 검증 근거이며 모든 조건의 보증이 아니다. 섭동에서는 모형의 퍼텐셜과 보존량을 분리해 설명한다.

공 끌기는 보이는 발사설정·초기 vx/vy 정의만 수정한다. 재실행 전 세계 해시가 그대로인지를 학생에게 확인하게 한다. 끌기 벡터를 무차원 초기 속도로 읽으며 vx −3~3, vy 0.2~3 범위 밖은 명시 거부한다. 반경·이심률은 원문 초기값에 남고 상황 단추는 직접 발사 모드를 해제한다.

A²=1+2EL²는 질량·중력계수 1인 역제곱힘에서만 성립한다. 섭동에서 검산오차가 0이 아닌 것을 실행 결함으로 가르치지 않는다. 방향변화는 두 A 벡터의 주각(rad)이며 누적 세차가 아니다. A가 거의 0인 원 운동에서는 방향있음이 거짓인 점을 함께 설명한다.

평가: 학생이 예상·조작·관찰·차이 설명을 모두 수행했는지 본다. 곁 그래프가 있다는 이유만으로 탐구 완료로 처리하지 않는다. `수값`·`좌표값`은 승인된 조회이고 `단계` 철자는 잠정이다. 미지원 글자 입력, 기록 이름·머리표·V1 통합의 미결정 경계를 유지한다.
