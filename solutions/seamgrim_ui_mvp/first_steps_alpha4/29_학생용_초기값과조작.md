# 29차시 - 만지고 다시 계산하기

슬라이더를 움직였다고 모든 계산이 즉시 바뀌는 것은 아닙니다. **초기값 편집**과 **실행 입력**을 먼저 구별합니다.

## 설명

이중 진자의 `초기각1`, `초기각2`는 새 실험을 시작할 때 쓰는 값입니다. 초기값 슬라이더나 추 끌기는 보이는 원문의 이 숫자를 바꿉니다. 이미 계산한 세계는 그대로이며, ▶로 새로 계산해야 바뀐 초기조건을 사용합니다.

확대와 이동은 화면만 바꿉니다. 공이나 추의 실제 좌표와 세계 해시는 바뀌지 않습니다.

## 예상

정지 상황에서 두 초기각을 0으로 두면 추는 어느 쪽으로 움직일까요? 슬라이더만 움직이고 ▶를 누르지 않았을 때 측정값이 달라질까요? 이유를 먼저 써 보세요.

## 실행

1. 첫걸음 29A 또는 공식 모음의 이중 진자를 엽니다.
2. 정지 상황을 고르고 ▶를 누릅니다. 각도와 속도가 0인지 봅니다.
3. 일시정지하고 첫 추를 오른쪽 아래로 끕니다. 원문의 `초기각1`이 바뀌었는지 확인합니다.
4. 측정값과 현재 세계는 아직 그대로인지 확인합니다. ▶로 다시 계산합니다.
5. 확대, 이동, 전체를 눌러 봅니다. 계산 결과와 화면 조작을 구별합니다.

현재 예제는 초기각 0~2라디안 범위를 사용합니다. 범위를 벗어난 끌기는 명시적으로 거부하며 숫자를 몰래 자르지 않습니다.

## 수정

작은차이를 0.001에서 0.1로 바꾸고 다시 실행합니다. 파란 실선과 주황색 비교 진자를 관찰합니다. 보이지 않는 차이를 화면이 임의로 과장하지 않으므로, 시간이 지나거나 확대해야 구별될 수 있습니다.

## 이유 설명

초기값 변경, 세계 입력, 화면 조작을 한 가지씩 예로 들어 설명하세요. 같은 실험을 비교하려면 무엇을 같게 두어야 할까요? 마찰 없는 모형의 에너지 변화가 보인다고 실제 마찰이라고 결론 내리지 마세요. 계산 간격과 고정소수 오차도 살펴야 합니다.
