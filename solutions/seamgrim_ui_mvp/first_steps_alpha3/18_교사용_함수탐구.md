# 18차시 교사용 · 근과 넓이를 비교하기

목표는 ‘그림이 예쁘다’가 아니라 반복 횟수·분할 수·오차의 관계를 설명하는 것입니다. 학생용 흐름은 예상 → 실행 → 값 수정 → 설명입니다. 원문은 한 번 실행합니다.

## 독립 해답

- 이분법의 시작 구간은 [1,2]입니다. k회 후 길이는 2⁻ᵏ, 가운데의 오차 상한은 2⁻ᵏ⁻¹입니다. 참근은 √2이며 제품의 출력값을 기대값으로 복사하지 않습니다.
- x²의 [0,1] 사다리꼴 n칸 결과는 `1/3 + 1/(6n²)`입니다. n=4이면 0.34375, n=8이면 0.3359375, n=16이면 0.333984375입니다.
- n칸과 2n칸의 정확수 오차비는 4입니다. Q32.32에서 1/3은 정확히 표현되지 않으므로 마지막 비트의 차이와 화면의 여섯 자리 반올림을 구별합니다.
- 함수 그림은 x²−2이고 넓이 계산은 x²입니다. 세로로 2만큼 옮긴 두 함수를 같은 함수라고 설명하지 않습니다. 현재 원문 설명은 두 계산을 명시적으로 구별합니다.

## 관찰 과제

학생이 ‘잔차가 작아졌으니 근의 오차도 똑같은 수다’라고 하면 두 정의를 다시 쓰게 합니다. 겹을 껐을 때 값이 그대로인 것도 확인합니다. 6회·4칸과 12회·8칸을 비교한 뒤 16회·16칸으로 예측을 시험합니다.

## 알려진 제작 상태

수치 계산은 Native 세 이름·실제 WASM에서 독립 식으로 검증했습니다. 근 그림·넓이 그림의 두 해석에서 세계 해시는 같습니다. 넓이 겹의 다각형 면적은 실제 사다리꼴 합과 대조합니다. 첫 칸은 삼각형이므로 겹친 꼭짓점을 넣은 퇴화 다각형으로 만들지 않습니다. 실제 Chrome에서 해석·상황 단추는 원문 정의만 바꾸고 ▶를 눌러야 그림이 바뀌는 것도 확인합니다. 곁 결과는 항목·값의 세로 표로 읽습니다. 전체 알파3 배포 완료, 최종 PDF·독립검토·Human PASS는 이 본문의 존재로 주장하지 않습니다.
