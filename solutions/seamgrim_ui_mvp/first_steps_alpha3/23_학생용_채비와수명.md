# 23차시 — 시작할 때 준비한 값은 언제 바뀔까?

## 설명

최상위 `채비`는 새 세계를 만들 때 자리를 준비합니다. 초기식은 처음 한 번 평가합니다. `(매마디)마다` 본문은 그 뒤 마디마다 실행합니다. 이 두 일을 섞으면 합계가 늘어야 할 때 시작값으로 계속 돌아갈 수 있습니다.

```ddn
채비 { 합계:수 := 10. }.
(매마디)마다 { 합계 <- 합계 + 2. 합계 보여주기. }.
```

이 설명은 최상위 채비의 수명입니다. 셈씨 안의 지역 이름, 일반 정의, 지속 파생 관계를 모두 같은 규칙으로 취급하지 않습니다.

## 예상

[23A](예제/23A_매마디누적.ddn)는 3마디를 실행합니다. 세 줄은 `12, 12, 12`일까요, `12, 14, 16`일까요? 합계의 시작값과 매마디 할 일을 다른 색으로 표시해 보세요.

## 실행

23A를 실행해 세 줄을 확인합니다. 한 마디 진행도 사용해 봅니다. 화면의 연속 실행 속도와 세계가 몇 마디 진행했는지는 다른 것입니다. 시간이 잠깐 흘렀다는 이유만으로 결과를 예상하지 말고 실제 마디 수를 확인하세요.

## 수정

초기값10을20으로, 더하는 값2를3으로 바꾸면 예상은23,26,29입니다. 다시 실행해 확인합니다. 이어서 시작값은 그대로 두고 매마디 본문에 `합계 <- 10.`을 먼저 넣어 보세요. 왜 매번12가 되는지 설명합니다. 이것은 초기화 규칙이 바뀐 것이 아니라 원문이 매번 다시결속한 것입니다.

## 이유 설명

저장한 상태를 복원하면 현재 합계를 이어받습니다. 처음부터 다시 시작하면 초기식으로 새 세계를 만듭니다. 따라서 합계14를 저장했다면 이어서 한 마디는16이고, 처음부터 한 마디는12입니다. 실제 저장 실험은27차시에서 합니다. 같은 화면을 다시 여는 것과 새 실행을 시작하는 것은 같지 않습니다.
