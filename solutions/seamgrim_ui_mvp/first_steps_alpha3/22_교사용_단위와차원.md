# 22차시 교사용 — 단위와 차원

목표: 같은 차원 환산과 다른 차원 거부를 구분한다. 학생에게 단위를 지워 오류를 피하도록 지도하지 않는다.

진행: 250cm와 3m×4m 손 계산 → 22A 실행 → 22B 진단 위치 읽기 → 시간을 길이로 고치기 → 차원의 역할 설명.

독립 기대값: 2.5@m, 12@m^2. 수정125cm는1.25@m, 50cm×200cm는1@m^2. 오류 원문은 같은 이름의 길이/시간 충돌을 가르치는 것이므로 진단 코드보다 잘못된 재결속이 거부되는지를 먼저 확인한다. 골든의 코드는 실제 Native·WASM 대조 결과에 결속한다.

평가: 숫자의 크기가 같아도 차원이 다르면 같은 양이 아님을 말할 수 있는가? 현재 지원 범위 밖의 단위는 미지원이며 이 수업을 모든 단위 지원 주장으로 넓히지 않는다.
