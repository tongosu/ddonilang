# 21차시 교사용 — 정확한 수

목표: 정확 정수·정확 분수·일반 소수 표시·글을 구별한다. JavaScript의 수 범위 설명을 언어의 수 의미로 대신하지 않는다.

활동: 네 결과 예상 → 원문 실행 → 정수/분수/글 수정 → 계산과 표시의 차이를 말로 설명. 학생이 글 `"1/2"`를 자동 분수로 생각하는지 확인한다.

독립 기대값: 정수 자릿수 덧셈으로 9007199254740994, 공통분모 6에서 2/6+1/6=1/2, 1/128=0.0078125. 여섯 자리 ties-to-even의 마지막 유지 자리 2로 0.007812. 문자열은 원문 그대로.

수정 과제: 9007199254740994+1=9007199254740995; 1/4+1/8=3/8. 기대값을 제품 출력에서 복사하지 않는다.

검증 단계는 README의 제작 상태를 따른다. Native·WASM 대조는 교육적 효과의 Human 검토를 대신하지 않는다. 현재 표시 정책은 영구 언어 규범이 아니다.
