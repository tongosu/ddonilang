# 24차시 교사용 — Basic Tensor

목표: 모양·0기반 좌표·끝 제외 범위·값 갱신을 구별한다. 고급 텐서 전체 지원으로 확대하지 않는다.

손 계산 표는[[1,2],[3,4]], 갱신 뒤[[1,8],[3,4]], 두 번째 열[[8],[4]]이다. 독립 기대값2,8,8,4. 첫 열 선택 수정은2,8,1,3이다.

학생이 축을 반대로 읽거나1..2에2를 포함하는지 확인한다. 실패 실습은 없는 칸 거부를 가르치며 원문의 위치를 확인하게 한다. 결과에 맞춰 모양을 임의로 바꾸는 우회는 하지 않는다.

현재 제품의 선택·갱신은 실행 원문 그대로 Native3/WASM으로 검사한다. 표를 그리는 UI를 만들었다는 주장은 하지 않는다. 이 수업은 표 값의 계산·관찰 차시다.
