# 25차시 교사용 — 공통·고정·상대

기존 alpha3_scene_time/relative/table_time 원문을 재사용한다. 마디0 처리 뒤x=1, 마디1 뒤2, 마디2 뒤3이므로3마디 현재3/고정0은1/직전은2이다. 벽시계 초나 화면 프레임 번호를 마디 번호로 가르치지 않는다.

진행: 예상 →25A/25B 곁 비교 →고정1 수정 →없는9번 오류 →관찰과 재생의 차이 설명. 셈그림은 선언 관계를 그리고 임의로 보기를 자동 선택하지 않는다.

검사: 실제 projection의 resolved_madi와 공의 x, 없는 마디 거부와 VM 전체 상태 불변. 고정 결과표도 현재 표 fallback 없이 검사한다. 브라우저 저장에 포함된 현재 이력 범위를 넘는 영구 과거 보장은 별도다.
