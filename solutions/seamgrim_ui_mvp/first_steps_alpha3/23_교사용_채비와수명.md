# 23차시 교사용 — 최상위 채비

목표: 최초 생성·매마디·복원·재시작을 구별한다. 같은 이름을 지역 정의와 뒤섞지 않는다.

독립 기대값: 첫 마디10+2=12, 다음14, 다음16. 수정은20+3=23,26,29. 본문 첫 문장으로10을 넣으면12가 반복된다.

진행: 결과 예상 →3마디 실행 →한 마디 진행 비교 →시작값과 증가량 수정 →복원과 reset의 차이 말하기. 27차시와 연결하여 두 번째 마디 저장 뒤16으로 이어지는지 확인한다.

제품 검증은 실제 WASM VM의 save/restore/reset와 CLI3을 대조한다. VM 검증을 브라우저 영구 저장·RD669 내구성 증거로 확대하지 않는다. 교실에서는 작업대의 명시 저장과 재열기를 별도 활동으로 수행한다.
