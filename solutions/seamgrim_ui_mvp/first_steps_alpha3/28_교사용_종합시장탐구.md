# 28차시 교사용 — 종합 탐구

기존 alpha3_market_lab.ddn을 재사용한다. 실제 시장과 선형 모형을 혼동하지 않는다. 세금 납부의 법적 주체가 아니라 가격 변화로 계산한 모형 내 경제적 부담을 다루는 수업이다.

독립 계산: Qd=Qs와Pc=Ps+t에서Pc=10+3t/8,Ps=10-5t/8,Q=50-15t/8. t=0,4,8에서(Pc,Ps,Q)=(10,10,50),(11.5,7.5,42.5),(13,5,35). 부담 합=t, 세수=tQ. 복리1000×1.05^5=1276.2815625, 단리1250.

활동: 최초 예상 →초기값 수정 →명시 재실행 →겹·곁 관찰 →가격표 작성 →식/그림 설명 →모형 한계. 학생이 값 변경만으로 현재 결과가 바뀐 줄 아는지 확인한다.

평가: 정답 숫자보다 가정·계산·표시·관찰을 구별하는가? “판매자 납부=판매자 전액 부담”이라는 최초 생각이 어떻게 달라졌는가? 현실 적용은 추가 자료와 모형 검증이 필요하다.
