# 18차시 · 함수의 답을 찾는 방법

이번에는 그림만 보는 대신 계산 방법을 바꾸고 오차를 비교합니다. 원문은 `samples/alpha3_function_lab.ddn`입니다. 한 번 실행하는 프로그램이므로 매마디는 쓰지 않습니다.

## 예상하기

`f(x)=x²−2`의 양의 근은 1과 2 사이입니다. 중간값에서 함수가 양수이면 오른쪽 끝을 중간값으로, 음수이면 왼쪽 끝을 중간값으로 바꿉니다. 한 번 할 때마다 구간 길이가 절반이 됩니다.

12번 나누면 마지막 구간 길이는 `1/4096`입니다. 그 구간의 가운데를 답으로 쓰면 참근과의 차이는 최대 `1/8192`입니다. 잔차 `f(근)`와 근 자체의 오차는 서로 다른 값입니다.

## 실행하기

**근 그림**을 고르고 ▶로 실행하면 으뜸의 점들은 `x²−2`의 표본입니다. 겹 ‘계산표시’는 계산으로 찾은 x축 위의 점입니다. 곁 ‘계산비교’에서 근과 잔차를 읽습니다. 겹을 꺼도 계산 결과는 변하지 않습니다.

**넓이 그림**을 고르고 다시 ▶로 실행하면 `x²`를 0부터 1까지 봅니다. 겹은 곡선 위 표본을 직선으로 이은 사다리꼴들입니다. 첫 조각은 왼쪽 높이가 0이어서 삼각형입니다. 위쪽 모서리와 실제 곡선 사이의 빈틈이 넓이 오차입니다. 겹을 꺼 곡선을 보고, 거칠게·촘촘하게를 골라 다시 계산해 조각 수와 오차가 어떻게 달라지는지 살펴봅니다.

같은 표는 `x²`의 0부터 1까지 넓이도 비교합니다. 정확한 넓이는 `1/3`입니다. 사다리꼴 8칸의 결과는 `0.3359375`, 16칸은 `0.333984375`입니다. 화면은 여섯 자리로 반올림하므로 계산값의 마지막 자리와 다르게 보일 수 있습니다.

두 해석은 같은 계산 결과를 다른 그림으로 읽는 방법입니다. 상황 단추는 원문의 `해석` 정의를 바꾸며 실행 전에는 화면 결과를 몰래 바꾸지 않습니다. 다시 실행해도 근·넓이·오차와 세계 해시는 같고 원문의 보기 선언만 달라집니다.

## 바꾸고 설명하기

1. ‘상황 바꾸기’의 거칠게·기본·촘촘하게를 고릅니다. 초기값 원문만 바뀌며 현재 세계는 바뀌지 않습니다. ▶를 눌러 다시 계산합니다. 직접 `이분횟수 := 12`를 6과 16으로 바꿔도 됩니다.
2. `나눈수 := 8`을 4와 16으로 바꿉니다. 두 계산은 각각 n칸과 2n칸을 씁니다.
3. 칸 수를 두 배로 하면 오차가 약 4분의 1이 되는지 확인합니다.
4. 근 찾기의 반복 횟수와 넓이 계산의 칸 수가 서로 다른 계산을 조절한다는 것을 자기 말로 설명합니다.

이 실험에서 횟수는 1~16, 칸 수는 1~32의 양의 정수로 바꿉니다. 0칸은 정의되지 않는 나눗셈이며 정상 결과로 취급하지 않습니다.
