# 17차시 교사용 안내 - 수 표시와 단위

집필·제품 대조 중인 알파3 자료입니다. 이 파일은 실행 합격표를 대신하지 않습니다.

## 수업 흐름

- 5분: 20 - 9.8 × 0.1 손 계산. 화면이 19.02를 보여도 계산 값을 강제로 19.02로 바꾸는 것은 아니라는 질문을 던집니다.
- 10분: 17A 세 줄 예상·실행. 셈씨는 이름 인자로 값을 받고 결과 자리에 넣습니다. 문자열 리터럴은 보정하지 않습니다.
- 10분: 17B 길이·면적 비교. 단위 기호가 달라도 차원은 같을 수 있다는 점을 강조합니다.
- 15분: MOD17 수정과 오류 복구. 거리에 시간을 넣는 실행과 면적에 길이를 넣는 실행을 각각 거부해야 합니다.
- 5분: 저장·다시 열기와 학생 설명. 비교하는 것은 숫자 크기뿐 아니라 차원입니다.

## 예상값의 독립 근거

17A: 손 계산 20 - 0.98 = 19.02, 부호 반전 -19.02. 따옴표 안의 글은 19.019999999. MOD17: 0 - 0.08 = -0.08, 200cm는 2m. 17B: 100cm는 1m, 4m × 5m는 20m². Fixed64 환산의 작은 차이는 내부 값을 바꾸지 않고 표시로 분리합니다.

속도를 1로 고치면 -0.1입니다. 거리 <- 2@s는 길이 씨와 맞지 않고, 면적 <- 1@m는 면적 씨와 맞지 않습니다. 실행에서 실제 나온 오류 코드를 교육 목표로 삼지 말고 **잘못된 차원의 재결속이 거부되고 실패 마디가 공개되지 않는가**를 확인합니다.

## 오해를 피할 설명

화면 소수 여섯 자리는 계산 정밀도의 선언이 아닙니다. 원문의 글을 숫자로 알아서 고치지 않습니다. 학생에게 실행 결과를 예상값으로 복사하게 하지 말고 손 계산과 비교하게 합니다. 단위 값은 현재 승인된 선형·온도 계약을 재사용하며 새 일반 affine 변환을 소개하지 않습니다.

셈씨의 결과 자리 넣기는 보통 이름을 바꾸는 재결속과 다릅니다. `:=` 세부 규칙을 이 수업에서 임의로 확대하지 않습니다.
