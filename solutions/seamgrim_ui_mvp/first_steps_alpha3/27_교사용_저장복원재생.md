# 27차시 교사용 — 저장의 세 종류

기대값은23A와 동일하다. 27A는 명시 뿌리 작품이며 정체를 명시적으로 만든 뒤 실행한다. 단일 원문의 저장으로 설명하지 않는다. 두 마디 뒤14 저장 →복원 한 마디16, 새 실행 첫 마디12. 원문·현재 상태·입력 전체 이력의 정보 차이를 세 칸으로 정리한다.

학생의 실제 작업대 저장·내보내기·가져오기 흐름과 WASM VM save/restore 검사를 구별한다. VM 복원 성공만으로 IndexedDB나 ZIP 사용자의 재열기 PASS를 주장하지 않는다. 원문 수정 뒤 상태 충돌을 임의 복구로 통과시키지 않는다.

RD669 전체 내구성, 생산자 수명 봉인 순번, 완전한 입력 없는 replay는 미완 경계다. 평가 질문: 같은 원문을 저장한 파일만 있으면 같은 진행 중인 게임으로 돌아갈 수 있는가? 같은 상태 파일만 있으면 모든 입력을 다시 볼 수 있는가? 둘 다 자동으로 그렇지 않다.
