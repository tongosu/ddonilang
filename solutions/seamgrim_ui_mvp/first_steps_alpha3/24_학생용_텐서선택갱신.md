# 24차시 — 표의 칸을 골라 바꾸기

## 설명

Basic Tensor는 같은 씨의 값을 정해진 모양으로 다룹니다. 이 수업에서는 2행2열의 수 표를 씁니다. 수학의 고급 텐서·계량이나 모든 다차원 연산을 배우는 차시는 아닙니다.

```ddn
표 <- (차림=차림[차림[1,2],차림[3,4]], 원소씨=셈수, 모양=(2,2)) 텐서로.
표[0,1] <- 8.
열 <- 표[:,1..2].
```

칸 번호는0부터 시작합니다. `[0,1]`은 첫 행의 두 번째 칸입니다. `:`는 해당 축 전체, `1..2`는1번부터 끝2번 직전까지입니다. 이 선택은 두 번째 열만 남깁니다.

## 예상

[24A](예제/24A_표의선택과갱신.ddn)에서 `옛표 <- 표.` 다음에 표의 한 칸을 바꿉니다. 옛표와 새 표에서 읽은 값은 같을까요? 선택한 열은 몇 행 몇 열일까요?

## 실행

24A를 실행하면 `2, 8, 8, 4`가 나옵니다. 첫 두 줄은 옛 값과 새 값, 다음 두 줄은 선택한 열의 위·아래 값입니다. 원문의 네 출력문과 결과 네 줄을 짝지어 보세요.

## 수정

8을10으로 바꿔 네 결과를 예상합니다. 선택을 `표[:,0..1]`로 바꾸면 첫 번째 열이므로1과3이 나옵니다. `표[2,0]`처럼 없는 행을 읽어 오류 위치를 확인한 뒤0이나1로 고칩니다. 없는 칸을 조용히0으로 채우는 결과를 기대하지 마세요.

## 이유 설명

옛표는 갱신 전 값을 유지합니다. 새 표를 바꾸는 것과 옛 값을 관찰하는 일을 구분해야 비교 실험이 가능합니다. 축 순서와 선택 범위를 그림으로 그려 친구에게 설명해 보세요. 같은 숫자 네 개라도 2×2와1×4는 같은 모양이 아닙니다.
