# 26차시 교사용 — 입력과 반응

20A의 원문/계약을 같은 bytes로 재사용한다. 기대값은(2+1)×2=6과2×2+1=5. 수정 예상은(2+3)×2=10과2×2+3=7이다.

실시간 누르기에서는 Release도 사건이므로 매마디 입력을 보지 않고 두 번 누른 최종값만6/5로 판정하지 않는다. 고정 단일 마디 사건 목록과 실제 CLI 파일 재생을 따로 검사한다.

학습 포인트: 사건/held상태, 사건순서/화면속도, 명시결속/이름자동연결, 실패마디/정상결과 구별. 두 번째 반응을 의도적으로 실패시키는 원자 검사에서는 기존 수직 제품 gate를 재사용한다. 잠정 호출명을 최종 SSOT 표면으로 가르치지 않는다.
