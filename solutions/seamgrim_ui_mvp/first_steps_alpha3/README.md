## 21~28차시 보충 실습 — 교육 확장, 출시 차단 조건 아님

[학생용 PDF](학생용_첫걸음_21-28차시.pdf)와 [교사용 PDF](교사용_첫걸음_21-28차시.pdf)를 함께 제공합니다. 21~28차시는 학생·교사 원고, 메뉴 활동과 실행 원문을 갖추었습니다. CLI 세 이름과 커밋 WASM에서 수·단위·채비·선택·시간·사건 순서·시장 결과를 대조했습니다. 27A는 명시 뿌리 작품이며 실행 상태 복원 뒤 이어가기를 검사했습니다. 실행 검증과 교육 내용의 독립검토·실제 학생 체험은 별도입니다.

첫걸음은 언어 학습, 예제 프로젝트는 창작, 탐구교재는 개념 탐구로 구분합니다. 기존 1~10은 `../first_steps/`, 11~16은 `../first_steps_alpha2/`, 17~20은 이 폴더를 재사용합니다. `docs/guides/DDN_정의중심_첫걸음_10차시`는 원고 계열이고 배포 원문의 별도 실행 근거로 세지 않습니다. 역사 교과 교재를 언어 교재 수로 합산하지 않습니다.

## 탐구교재 8개 — 제작 순서

1. 기존 함수와 근 찾기: 예상·방법 변경·오차 비교.
2. 기존 이중 진자: 초기조건 비교와 계산 간격 오차를 구별.
3. 기존 작은 시장: 가정 변경·재실행·결과 설명.
4. 미분과 적분: 함수 실험실을 재사용해 작은 변화/누적량 탐구.
5. 에너지 손실과 수치 오차: 진자 자료를 재사용, 물리 손실과 수치 오차 구별.
6. 세금 부담: 시장 자료를 재사용, 납부자와 경제적 부담 구별.
7. 같은 역사 사건의 다른 사료: FUTURE, 출처·사실·해석·반사실 연구 뒤 제작.
8. 화학 동적 평형: FUTURE, 모형 가정과 실제 현상 검토 뒤 제작.

기존 대표 3개부터 품질을 개선합니다. 모든 교재는 예상 → 조건 변경 → 관찰 → 비교 → 이유 설명으로 구성하며 그래프 출력만으로 교육 완료를 주장하지 않습니다. 기존 course·교재·guide·교육 pack의 경로와 바이트 해시를 `tools/education_content_inventory.mjs`로 분류합니다. 다른 writer의 원고를 자동 통합하거나 이 후보 30개·8개가 모두 완성됐다고 주장하지 않습니다.
