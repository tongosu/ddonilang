# 25차시 — 지금과 과거를 같은 화면에서 비교하기

## 설명

공통 마디는 세계의 현재 마디를, 고정 마디는 정해 둔 마디를, 상대 마디는 현재에서 정해진 차이만큼 떨어진 마디를 봅니다. 이는 화면 관찰의 시간 선택입니다. 과거를 본다고 세계를 되감거나 입력 기록이 새로 생기지 않습니다.

```ddn
(번호=0) 표준시간.고정마디
(차이=-1) 표준시간.상대마디
```

시간 인자는 보기 관계에 붙입니다. 이 차시에서는 제품에 보존된 공통·고정·상대 보기만 사용합니다. 없는 과거를 현재 그림으로 대신 보여 주면 비교가 아니라 잘못된 관찰입니다.

## 예상

25A의 가로 위치는 마디마다1씩 늘어납니다. 3마디 후 현재 공의 x는3입니다. 고정0번 마디 그림의 x는1일까요0일까요? 0번 마디는 첫 마디 처리를 마친 상태라 x=1입니다. 25B의 직전 마디는 x=2입니다.

## 실행

첫걸음25A를 실행하고 으뜸과 곁을 비교합니다. 이어서25B를 실행합니다. 고정 그림은 그대로이고 상대 그림은 현재와 함께 바뀝니다. 25C는 같은 구분을 결과표로 보여 줍니다. 보개 이름이 여럿이면 원문에서 선언한짜임을 명시적으로 선택해야 합니다.

## 수정

고정 번호0을1로 바꿔3마디 실행하면 고정 그림은x=2입니다. 아직 만들지 않은9번으로 바꾸면 오류가 나야 합니다. 상대 차이-1을0으로 바꾸면 현재와 같은 마디를 봅니다. 실패한 보기 선택이 세계를 진행시켰다고 취급하지 마세요.

## 이유 설명

곁을 닫거나 다시 여는 것은 관찰 조작입니다. 세계의 x를 다시 계산하는 명령이 아닙니다. “고정 그림”, “직전 그림”, “입력 재생”의 차이를 각각 한 문장으로 설명해 보세요. 지원되는 이력은 무한하지 않으며, 이 수업은 무한한 과거 저장을 보장하지 않습니다.
